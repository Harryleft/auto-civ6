信念引擎 · 记录与推理

每次成功的查询/动作自动入账为 Observation（只存规范化事实 + 指纹，原文归遥测）；信念、预测、计划可被后续证据结算或推翻；事件日志 append-only，删除即墓碑。

  • derivation 规则自动派生信念与预测
  • 预测按到期结算：确认 / 否定 / 迟到
  • coverage 审计区分系统产出与模型自报
🛡️

治理门禁 · 动作把关

高影响 / 高不可逆动作必须先走：目标 → 提案 → 批评 → 议会仲裁 → hash-bound ActionIntent；未授权调用在触碰游戏前即被拒绝。

  • 概率与置信度始终分离，不合成单一分数
  • 议会顺序：硬约束 → 预算锁 → 优先级 → Pareto → 机会成本
  • 写游戏仅单一通道，部门只能建议不能执行
💾

持久化 · 可重放证据

五类数据全部按 {civ}_{seed} 分键落盘：信念事件、工具日志（全部调用+耗时+结果）、回合日记（快照+五段反思）、空间注意力（研究用）、存档（恢复点）。

  • 读档产生 epoch 标记，作废旧授权
  • 遥测镜像事件 → Convex 成绩站点
  • 崩溃可经存档 + 自动恢复继续
