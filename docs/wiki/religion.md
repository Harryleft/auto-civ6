# 宗教（Religion）（Civ6 知识库）

> **定位**：万神殿 / 信仰 / 信条 / 宗教单位 / 传播与宗教胜利的机制知识库。
> **何时读**：选择万神殿、创建或强化宗教、购买宗教单位、评估宗教胜利进度、应对敌方传教时。
> **关联清单条目**：CHECKLIST.md「I. 宗教与信仰」。

## L0 决策速查（10 条内，可直接依据决策）

1. 信仰是资源不是垃圾：无计划囤积 = 机会成本。要么花（买单位 / 伟人 / 纪念碑式买移民），要么明确留到黄金时代，否则随时可花掉。
2. 首个万神殿尽早抢：25 信仰（标准速度）即可建立；神级 AI 抢得快，万神殿被选完就再也建立不了，因此开局先把信仰攒到 25。
3. 万神殿优先选适合本图的：沙漠民俗 / 极光之舞（荒漠 / 冻土圣地相邻信仰）、丰收仪式（成长 + 建造者）这类早期立竿见影的，其次才考虑后期型。
4. 大预言家先到先得、总数有限：圣地 + 圣祠 / 寺庙产大预言家点；预言家到手后尽快在圣地「创建宗教」，拖到战争或 AI 抢光会白费。
5. 创建宗教时四类信条各选 1（创始人 / 信徒 / 崇拜 / 强化），先定路线再选：宗教胜利选传播强化，征服选「十字军」，发育流选「劳作伦理 / 耶稣会教育」把信仰转成生产力。
6. 宗教单位只能从「你的宗教占多数」的城市购买；城市被异教转化后先审判官清异教，再补买单位。
7. 神学战斗靠使徒：使徒 110 战力 > 传教士 100，「辩论家」晋升 +20 战力是战斗核心；胜方回充能、败方掉血，别拿传教士主动开打。
8. 宗教胜利 = 你的宗教成为**所有**其他文明**每座城市**的多数宗教（含盟友、含无宗教的刚果）；定期查 `get_religion_spread`，优先压死最接近宗教胜利的 AI。
9. 对手传教防范：敌方传教士 / 使徒进境说明会被转化——军事单位宣战清剿、使徒「谴责异端」净化、审判官守自家城，三选一或组合用。
10. 信仰与政策联动：黄金时代「纪念碑式」用信仰买开拓者 / 建造者 / 商人；神权政府 +「大元帅礼拜堂」用信仰买陆战单位；神权下宗教单位造价打折。

## L1 核心机制

### 信仰的获取途径

- **圣地（Holy Site）**：占星术解锁，是信仰主产区；基础相邻加成来自山脉 / 自然奇观 / 区域密度，可被万神殿信条放大。
- **圣地建筑**：圣祠（Shrine）、寺庙（Temple）提供信仰并产出大预言家点。
- **万神殿信条**：地块型信条（沙漠民俗、极光之舞、圣径、巨石圈、大地女神等）让特定地形 / 改良 / 奇观产信仰。
- **政策卡**：早期「神权君主（God King）」首都 +1 信仰 +1 金币；后续市政树有更多宗教相关卡。
- **宗教信条**：创始人信条「朝圣」按追随城市给信仰；信徒信条「劳作伦理」把圣地相邻转成生产力。
- **圣物 / 伟人 / 城邦**：圣物（Relic）产信仰；部分伟人（使徒殉道）与城邦宗主国加成也提供信仰。
- **价值判断**：信仰随时代相对贬值（前期 25 开万神殿，后期一个伟人动辄几百），早期信仰尤其值得早点变现。

### 万神殿（Pantheon）

- **建立**：花费 25 信仰（标准速度，随游戏速度缩放），每个文明只能选 1 个；生效立即且永久——创建宗教后万神殿信条仍然保留。
- **抢选机制**：万神殿数量有限、先到先得，全部被选完后无法再建立；神级 AI 的信仰收入快，开局不优先攒 25 信仰就可能错过。
- **选择逻辑**：优先「地形契合」的信条（本图荒漠多选沙漠民俗、冻土多选极光之舞、丘陵/矿多选匠神等），次选通用节奏型（丰收仪式、大地女神），再考虑配合奇观（神圣灵感）或战争（战神、锻造之神）。
- 不确定具体加成数值时看信条文字描述，以游戏内为准。

### 大预言家与创建宗教

- **大预言家点（Great Prophet Points）**：圣地 +1 / 回合、圣祠 +2、寺庙 +3（标准速度，以游戏内为准）；奇观「巨石阵」直接给点数或预言家。
- **数量有限**：本局大预言家总数 ≈ 玩家数，先到先得；全部被领走后，剩余大预言家点失效（白攒）。
- **创建宗教**：预言家移动到己方**圣地**（或其相邻格）→ 执行「创建宗教」→ 选宗教名 / 图标 + 4 类信条各 1 个。
- **限制**：每个文明最多拥有 1 个宗教；已有宗教后大预言家无法再建第二个，也不要让预言家裸奔在野外（平民单位，会被敌方军事单位消灭或俘虏，以游戏内为准）。

### 信条四类与选择逻辑

- **创始人（Founder）**：按追随城市 / 信徒数量生效，收益随传教范围扩大：什一税（金币）、教会财产（金币）、朝圣（信仰）、世界教会（文化）、守护信仰（己方领土 +10 战斗力）等。
- **信徒（Follower）**：城内生效，改造城市产出：劳作伦理（圣地相邻 = 生产力）、合唱颂歌（圣祠 / 寺庙产文化）、耶稣会教育（信仰购买校园 / 剧院区建筑）、哺育世界（圣祠 / 寺庙产食物）、沉思冥想（宜居度）等。
- **崇拜（Worship）**：解锁可在圣地建造的崇拜建筑（清真寺、教堂、宝塔、犹太会堂等），各提供信仰与额外效果（如清真寺强化传教士充能，以游戏内为准）。
- **强化（Enhancer）**：强化传播与宗教战争：传教热情（传播强度 +10）、神圣秩序（宗教单位信仰造价 -30%）、巡游祭司（压力范围扩大至 10 格）、十字军（对异教文明 +10 战斗力）等。
- **选择逻辑**：先定宗教路线（进攻 / 防守 / 辅助发育）再选；即使不走宗教胜利，「劳作伦理 + 圣地相邻」也是把信仰转成生产力的经典组合。

### 宗教单位与神学战斗

- **传教士（Missionary）**：100 神学战力，多次「传播宗教」充能；不能主动发起神学战斗，只能防御（或逃离）。
- **使徒（Apostle）**：110 神学战力，是神学战斗主力；充能用于传播、**谴责异端**（清除城内异教压力）、**发动宗教审判**（Inquisition，解锁审判官）；训练时获得随机晋升（辩论家 +20 战力、殉道者死亡产圣物、劝化者削弱异教传播等）。
- **审判官（Inquisitor）**：只能在己方领土内使用，清除自家城市中的异教压力；需先由使徒「发动宗教审判」后才能购买。
- **古鲁（Guru）**：0 战力，治疗相邻友方宗教单位（+60 HP，以游戏内为准），不参与传播。
- **神学战斗规则**：异教宗教单位相邻时可发起；胜方回充能并对败方造成伤害，败方掉血乃至被消灭（其宗教在附近城市的压力受损，以游戏内为准）；战力差决定伤害。
- **军事单位可攻击宗教单位**（视同平民）：宣战后清剿敌方传教士是防转化最直接的手段。

### 宗教传播机制（压力）

- **压力（Religious Pressure）**：每座信奉某宗教的城市，每回合向范围内的城市施加压力；压力决定城市的**多数宗教**。
- **传播行为**：传教士 / 使徒的「传播宗教」一次性大幅增加目标城压力并可直接转化；使徒「谴责异端」削减异教压力。
- **压力范围**：城市压力基础约 5 格，强化信条「巡游祭司」扩大至 10 格（以游戏内为准）。
- **判定**：多数宗教 = 压力最高者；神学战斗胜利、净化、传播都能改变城市归属。**每回合通过 `get_religion_spread` 核对传播进度**，别等胜利倒计时才发现方向反了。

### 宗教胜利与对手压力防范

- **胜利条件**：你的宗教成为**所有其他文明每座城市**的多数宗教——包括盟友和无宗教文明（如刚果）；被消灭的文明不计数。
- **进攻策略**：先压最接近胜利的 AI（避免被反超）；优先转化对方圣城（Holy City），圣城一失其宗教压力大幅削弱；用使徒打神学战清对方单位再落地传播。
- **防守策略**：审判官守家清异教、使徒净化边境、军事单位宣战清剿入侵的宗教单位；被异教转化会反向给对手加进度，自家城市安全是底线。
- **世界议会**：过度传教可能触发「宗教紧急事件」，被宣战围殴；反过来对手传教凶时也可主动发起紧急事件借力。

### 宗教与同盟 / 外交的关联

- **转化他人城市会产生 grievances**（对方有自己宗教时更严重），过度传播可能引发谴责、战争或宗教紧急事件；但宗教胜利又必须转化盟友——这是路线固有矛盾，提前规划先后顺序。
- **同盟不豁免宗教胜利**：盟友城市一样要皈依，先结盟发育、后转化收割是常见节奏。
- 城邦方面：部分城邦（如瓦莱塔、耶路撒冷、埃里温等）与信仰 / 宗教单位直接挂钩，宗主国加成值得注意。

### 信仰购买

- **可购买对象**：
  - 宗教单位：传教士 / 使徒 / 审判官 / 古鲁（需对应市政解锁，使徒需「神学」、审判官需「改革教会」，以游戏内为准）。
  - 崇拜建筑：持有对应崇拜信条后可在圣地用信仰建造。
  - 伟人：已创建宗教后可用信仰购买伟人（基础成本 200 + 50×时代数，以游戏内为准）。
  - 特定单位：黄金时代献礼「纪念碑式」用信仰买开拓者 / 建造者 / 商人；神权政府 +「大元帅礼拜堂」用信仰买陆地军事单位。
- **购买条件**：宗教单位只能从**你的宗教占多数**的城市购买；政策卡 / 信条（神圣秩序、神权政府）可打折。
