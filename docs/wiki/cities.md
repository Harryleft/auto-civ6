# 城市（Cities）（Civ6 知识库）

> **定位**：城市增长 / 生产 / 忠诚 / 区域 / 总督的机制与决策知识库，面向神级单人局。
> **何时读**：每座城市的建造决策（生产队列）、增长停滞、忠诚度告警、铺城与区域规划。
> **关联清单条目**：CHECKLIST.md F. 城市（生产队列、增长与忠诚）。

## L0 决策速查（10 条内，可直接依据决策）

1. **城市数量是长期复利的主要来源**：神级标准图尽早铺到 7~10 城；每城约使科技/市政成本 +5%，但 4 人口以上城市的产出通常远超该成本（见 L1「城市数量与成本缩放」）。铺城窗口在前中期，错过不补。
2. **食物盈余 ≤0 或增长 >15 回合 = 必须修**：优先级——农场改良 → 粮仓/水磨 → 国内商路喂食 → 城市焦点切「增长」→ 检查住房与宜居度（见 L1「增长与停滞」）。
3. **负忠诚度城市立即派总督**（任意总督 +8 忠诚/回合），配合驻军（+5/回合）与忠诚政策卡；忠诚归 0 变自由城市，随后会被压力最大的邻国吞并。
4. **开拓者白走是高额浪费**：建城前确认——与最近城市中心距离 >3 格（否则不能建）、有淡水（住房 +2）、3 环内有可工作地块、目的地无蛮族营地与敌方近城忠诚压力。
5. **每城五查**：增长、生产、忠诚度、城墙、驻军（决策硬规则）；边境城先出城墙与驻军，再谈产能。
6. **建城先占战略资源**：铁、马、硝石（后期铝/铀）；缺战略资源 = 单位断档，神级下尤其致命；其次占奢侈品与自然奇观。
7. **区域成本随研究进度上涨**：关键区域（学院/圣地/商业中心）尽早「拍地」锁定成本与地块，晚建可能贵一倍以上（见 L2）。
8. **人口逼近住房/宜居度上限时按「停止增长」**：避免宜居度惩罚拖累整城产出与增长。
9. **神级开局节奏**：先稳住首都 + 2 分城共 3 核心城（总督给平加拉或马格努斯），再持续铺城；每城独立自足（淡水、住房、1~2 个关键区域）。

## L1 核心机制

### 城市面板要素
- **人口**：城市核心资源；每人口工作一个地块（城市中心 3 环内），每人口消耗 2 食物。
- **食物**：产出 − 消耗 = 盈余，盈余积累满增长阈值即 +1 人口；盈余 ≤0 则增长停滞。
- **住房（Housing）**：容纳人口的上限；人口接近/超过住房后增长大幅衰减。
- **宜居度（Amenities）**：由奢侈品、娱乐中心等提供；低宜居度惩罚增长与全部产出。
- **忠诚度（Loyalty，R&F+）**：0~100，归零变自由城市（详见下）。
- **生产力（Production）**：地块 + 建筑 + 区域邻接 + 政策/总督修正，决定建造速度。
- **金币/科技/文化/信仰**：来自工作地块、区域与建筑，按面板汇总；城市焦点可引导市民分配。

### 增长与停滞
- 增长阈值：人口 n → n+1 需 15 + 8n + n^1.5 食物（约，以游戏内为准）；盈余积累满即增长。
- 住房不足：人口超过住房时盈余打折，超出越多越狠，最终完全停滞（上限约住房 +5，以游戏内为准）。
- 宜居度不足：同样压制增长（-10% / -30% 两档，见 L2）。
- 修增长的优先级：① 农场改良 + 粮仓/水磨（住房与食物双修）→ ② 国内商路（目的地城市 +食物+产能，随双方区域数增加）→ ③ 城市焦点切「增长」→ ④ 宜居度（奢侈品/娱乐中心）。
- 高人口城依靠区域与建筑（学院/剧院）提供「不占人口」的科研文化产出：人口停滞不代表全面停滞。

### 生产队列与城市焦点
- 生产队列：可一次排多个项目（单位/建筑/区域/奇观/项目）；每回合产能自动累积到当前项目；切换项目不损失已累积产能。
- 城市焦点（Focus）：市民按焦点自动分配地块——增长 / 生产 / 金币 / 科技 / 文化 / 信仰；手动指派地块可覆盖焦点。
- 购买：金币可买建筑与单位（约 4 倍生产成本，后期略降，以游戏内为准）；信仰只能买宗教单位与伟人。危急时金币补单位比等产能快。
- 「停止增长」按钮：人口将超住房/宜居度上限时手动停增长，避免惩罚。

### 区域（District）类型与邻接加成
- 区域上限：约 1 + ⌊人口/3⌋（以游戏内为准）；区域占地块且不可撤销，先规划再建造。
- 主要区域（GS 标准邻接，细节以游戏内为准）：
  - **学院（Campus）**：科技；邻接山脉 +1 科技，每 2 个相邻区域 +1，邻接礁石/地热裂缝 +2。
  - **圣地（Holy Site）**：信仰；邻接山脉 +1 信仰，邻接森林 +1，自然奇观 +2，每 2 个相邻区域 +1。
  - **商业中心（Commercial Hub）**：金币；邻接河流 +2 金币，邻接港口 +1，每 2 个相邻区域 +1。
  - **工业区（Industrial Zone）**：产能；邻接矿山/采石场 +1，邻接水渠/堤坝/运河 +2，每 2 个相邻区域 +1。
  - **剧院广场（Theater Square）**：文化；邻接奇观 +2 文化，每 2 个相邻区域 +1。
  - **军营（Encampment）**：+1 住房；GS 中无产出邻接，提供驻军与单位经验加成。
  - **港口（Harbor）**：金币/食物；邻接商业中心 +2 金币，邻接海产资源 +1，每 2 个相邻海岸地块 +1。
  - **娱乐中心 / 水上乐园**：宜居度；覆盖范围（约 6 格）内城市获得宜居度，无强邻接。
  - 其他：水渠（淡水/住房）、堤坝（防洪）、运河（GS 移动）、航空港（GS 空中单位）、政府区（R&F 唯一）、外交区（GS 唯一）、社区（住房）。
- 邻接加成可被政策卡翻倍（如「自然哲学」学院×2、「圣经」圣地×2），伟人与文明能力另有修正。

### 区域放置规划
- **先算后拍**：用地图现有的山脉/河流/资源/奇观 + 区域互相加成确定最高邻接位；区域一旦拍下不可移动。
- **区域扎堆**：2 个区域相邻各得 +1（对应产出）；学院贴山脉，工业区贴矿山/水渠，商业中心贴河湾。
- **拍地锁成本**：区域成本随研究进度上涨——即使建筑科技未好也先拍下区域，锁定成本与地块。
- 城市中心 3 环内地块均可放区域；注意与市中心、其他区域、奇观不重叠，并为未来奇观保留位置。

### 住房来源
- 淡水建城：城市中心住房 5（无淡水仅 3）——建城时优先级最高的「免费住房」。
- 粮仓 +2、水磨 +2（需淡水）、水渠 +2（城市无淡水时更高，约 +6，以游戏内为准）、社区 +2 起（随人口与科技增长）。
- 军营 +1 住房，部分政策卡提供少量住房。
- 决策链：淡水 > 粮仓/水磨 > 水渠 > 社区；住房不够先修住房再谈人口。

### 忠诚度机制（R&F+）
- 每回合忠诚度按压力修正；归 0 → 自由城市（Free City），随后可能被压力最大的邻国吞并。
- **压力来源**：
  - 邻国城市：约 9 格内外国城市按人口与距离施压（首都与黄金时代城市压力更大）；
  - 己方城市产生正向压力互相支撑——铺城连片 = 忠诚链，孤立飞地必然忠诚崩；
  - 总督 +8/回合；驻军 +5/回合；政策卡与阿玛尼总督称号额外加；
  - 时代：黄金时代 +压力，黑暗时代 −压力（数值以游戏内为准）。
- **应对**：负忠诚立即派总督 → 驻军 → 忠诚政策卡；远离 AI 巨城铺城，或先清掉压力源；边境城靠己方城市链撑忠诚。
- 神级注意：AI 城市人口高、铺得密，贴着 AI 首都铺的城忠诚必红——要么速战速决拿下压力源，要么后退留缓冲。

### 城市数量与成本缩放
- 科技/市政成本：每城约 +5%（不含首都在内的城市数；速度与难度另有修正，以游戏内为准）。
- 开拓者：成本随已建城市数递增（约基础 80 锤 + 每城 +20 锤，以游戏内为准）——越早铺越便宜。
- 区域：成本随全局研究进度上涨（公式见 L2）——早拍便宜。
- 综合：新城 1~3 人口为净投入期，4 人口后开始摊薄成本；神级 AI 铺城更快，扩张窗口在前中期。

### 总督体系（R&F+）
- 7 位总督，靠市政树获取总督点数（开局 1 点），每城限 1 位，可随时移动。
- 常见选择（神级单机）：
  - **马格努斯（Magnus）**：铺城流核心，称号「供给」（Provision）使本城生产开拓者不消耗人口。
  - **平加拉（Pingala）**：首都/科技城，按人口 +科技/文化，可配伟人点称号。
  - **阿玛尼（Amani）**：边境忠诚危机城（+8 忠诚/回合）；称号可对外施加忠诚压力。
  - **维克多（Victor）**：前线被围城，强化城防与驻军。
  - **梁（Liang）**：基建城，建造者次数 +1。
  - **雷娜（Reyna）**：金币城（商业/港口城）。
  - **摩柯沙（Moksha）**：宗教城，信仰与传教加成。
- 总督点数投给「当下最痛」：缺人 → 平加拉/马格努斯；忠诚红 → 阿玛尼；被围 → 维克多。
