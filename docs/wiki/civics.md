# 市政（Civics）（Civ6 知识库）

> **定位**：市政树 / 政策卡 / 政府
> **何时读**：选市政、换政策卡、切换政府
> **关联清单条目**：C. 市政

## L0 决策速查（10 条内，可直接依据决策）

1. **市政与科技是两条并行研究线**：科技吃科研、市政吃文化。神级下不要只追军事科技——封建主义（Feudalism）解锁「农奴制」让每个建造者 +2 次改良，比多数中后期军事科技更能缓解食物与改良瓶颈。
2. **主动触发鼓舞（Inspiration）**：触发后立即获得该市政 **50% 进度**。研究前先看鼓舞条件；条件"差一步达成"时，先压着市政不完成，做完触发动作再回来研究，别白白浪费加速。
3. **政策卡每回合可免费重排**：按当前瓶颈切换——扩张期插经济卡（殖民 +50% 开拓者产能、给养/商路类卡），战争期换军事卡（单位产能、经验、攻城类），和平期换基建/金币卡；不要一套卡用到底。
4. **尽早解锁政治哲学（Political Philosophy）换掉酋邦**：其自身 +1 通配槽，并解锁一层三大政府——扩军走寡头政治、爆铺/奇观走独裁政治、文化/科技城邦走古典共和。
5. **封建主义是爆铺/改良拐点**：优先于"凑科技"安排，农奴制配合农场改良解决食物瓶颈；一次建造者产出翻倍级杠杆，是神级中前期滚雪球的核心节奏点。
6. **外交服务（Diplomatic Service）解锁同盟**：和平发展、外交/文化胜利路线优先走；同盟带来商路加成与外交支持（GS 下等级同盟收益更高），同时是外交胜利的政策基础。
7. **换政府前先榨干当前执政红利**：切换后旧政府的「传承加成（Legacy Bonus）」只持续有限回合（以游戏内为准），两次切换之间要规划好时机，不要频繁无脑换。
8. **前期每城保证文化产出**：纪念碑优先、尽早剧场广场；文化落后 = 政策卡数量与市政解锁全面落后。神级 AI 文化领先时，中后期要盯防其文化胜利进度。
9. **部分市政解锁区域/建筑**（如政府广场等，以游戏内为准）：市政路线要与区域规划对齐，先定路线再铺城，避免城市定型后补区域。
10. **中后期按胜利路线定向走市政**：文化胜利走环境保护（国家公园）/大众传媒（广播中心）线；外交胜利走外交服务与同盟线；终局全球化解锁第四层政府，为最终冲刺加码。

## L1 核心机制

### 1. 市政树结构

- 市政树（Civic Tree）与科技树平行，由**文化产出**驱动，共 **8 个时代**：远古 → 古典 → 中世纪 → 文艺复兴 → 工业 → 现代 → 原子能 → 信息，与科技树时代一一对应。
- 首个市政固定为**法典（Code of Laws）**（无鼓舞），解锁最初的政策槽位与政策卡使用；之后大部分市政呈链式前置（多数只有一个前置），少数有分支。
- 每个市政解锁 0~n 张**政策卡**，部分市政还解锁区域/建筑/机制（如对外贸易解锁商路与商人、外交服务解锁同盟——以游戏内为准）。
- 触发条件显示在市政研究界面（Research/Civics 面板）与市政百科条目中；研究前务必先读。

### 2. 鼓舞（Inspiration）

- **机制**：达成某市政的鼓舞条件时，立即获得该市政 **50% 的研究进度**（与科技的尤里卡 Eureka 完全同构，对应关系见 [science.md](science.md)）。
- 鼓舞**只能触发一次**；条件达成瞬间自动结算，无需手动确认。
- 常见触发方向：城市数量、人口、改良数量、单位/建筑数量、外交关系（同盟/城邦）等——具体数值以游戏内提示为准（L2 表 4 仅列示意）。
- 操作要点：研究一个市政前先读其鼓舞条件并评估"能否顺手触发"；能触发的先触发再研究，不能触发的直接研究，避免空等文化产出。

### 3. 政策卡（Policy Card）与槽位

- 政策卡分四类：**经济 / 军事 / 外交 / 通配（Wildcard）**；通配卡可放入任意类型的槽位（含通配槽）。
- **槽位来自政府**：政府决定各类型槽位数量；部分市政（如政治哲学 +1 通配）、奇观与个别机制可额外增加槽位（以游戏内为准）。
- 政策卡**每回合可免费调整**（无冷却、无金币消耗），是游戏中响应局势最灵活的系统——神级下每回合都应扫一眼槽位是否匹配当前瓶颈。
- 政策卡解锁靠市政：市政研究完成即永久解锁对应卡片，可随时上槽/下槽。
- 典型配对（详见 L2 表 5）：扩张期「殖民」；改良期「伊尔库姆」「农奴制」；战争期军事产能/经验卡；后期外交支持卡与科研产能卡。

### 4. 政府类型演进

- 起始政府为**酋邦（Chiefdom）**（1 经济 + 1 军事槽，以游戏内为准），能力很弱，是第一个要替换的目标。
- 政府分**四层**（层数 = 时代梯度）：
  - **一层（政治哲学解锁）**：独裁政治 / 寡头政治 / 古典共和——各有执政加成与不同的槽位配比，并统一获得 +1 通配槽。
  - **二层（中世纪～文艺复兴市政解锁）**：君主制 / 神权政治 / 商人共和——槽位与加成升级，适配不同路线（宗教、经济、防御）。
  - **三层（现代市政解锁）**：法西斯主义 / 共产主义 / 民主制——民主制带外交槽，法西斯偏军事槽，共产主义偏产能（以游戏内为准）。
  - **四层（信息时代，GS）**：数字民主 / 企业自由主义 / 合成技术官僚——由终局市政（如全球化）解锁，槽位最多。
- **切换机制**：可随时切换（无冷却，以游戏内为准）；切换后旧政府提供**传承加成（Legacy Bonus）**持续有限回合，新政府立即生效——换政府的时机 = 新旧加成叠加的窗口期。

### 5. 关键市政

- **法典 Code of Laws**：起点，解锁政策系统与初始槽位。
- **工艺 Craftsmanship**：解锁「伊尔库姆」（建造者 +30% 产能），改良提速，前期铺设施节奏核心。
- **早期帝国 Early Empire**：解锁「殖民」（开拓者 +50% 产能），爆铺路线必走。
- **政治哲学 Political Philosophy**：解锁一层政府 + 额外通配槽，市政树最重要的节点之一。
- **封建主义 Feudalism**：解锁「农奴制」（建造者 +2 次），并通往后续经济/军事市政；食物与改良瓶颈的转折点。
- **外交服务 Diplomatic Service**：解锁同盟机制及外交政策卡；外交/文化胜利的关键前置，和平扩盟的核心。
- **环境保护 Conservation**：解锁国家公园与自然学家（旅游来源，文化胜利）；现代时代文化线关键。
- **大众传媒 Mass Media / 全球化 Globalization**：分别解锁广播中心类旅游建筑与第四层政府（以游戏内为准），终局冲刺节点。

### 6. 市政与胜利路线

- **文化胜利**：政策卡是旅游加成的放大器（大众传媒线、环境保护的国家公园），市政进度直接决定旅游上限；同时文化产出本身加速市政（正反馈）。
- **外交胜利**：外交服务解锁同盟，同盟与外交政策卡产出外交支持（GS 世界议会），是外交点数的稳定来源。
- **科技胜利**：市政主要提供产能/科研类政策卡与更强政府槽位，终局市政（全球化等）配合科技线收尾。
- **征服胜利**：市政提供军事政策卡（单位产能/经验/攻城加成）与战争相关的政府加成，但优先级上先保证经济市政撑起兵源。
