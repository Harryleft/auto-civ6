# 科技（Science）（Civ6 知识库）

> **定位**：科技树结构与时代划分、研究成本规则、尤里卡（Eureka）触发机制、科技胜利前置科技的机制说明与决策速查。
> **何时读**：选择研究项目、规划科技路线、评估科研进度、准备科技胜利时。
> **关联清单条目**：B. 科技

## L0 决策速查（可直接依据决策）

1. **科技落后通常是城市少的结果，先扩张再追科研**：新城学院与人口带来的科研增量，远超「每城研究成本 +5%」的惩罚；神级下宁可先铺城、后集中补科研。
2. **尤里卡要主动触发**：选科技前先看触发条件，条件接近满足时再点该科技，触发后立即白赚 50% 研究量；触发不了就优先点「能触发」的那一项，不白点。
3. **路线从目标反推**：要打仗先走攻城链（见 L1 特殊科技），要科技胜利先奔火箭学（Rocketry）链；平均推进科技树是神级大忌。
4. **每城建学院（Campus）、人口点学者槽位**：学院与学者槽是科研主产出，没学院的城市在神级下基本不贡献科研。
5. **科技胜利本质是生产问题**：宇航中心（Spaceport）与太空项目吃的是高产能城，科研只是入场券；火箭学落地前就锁定一座产能首都。
6. **攻城前先核对攻城科技**：砌砖（Masonry）/工程学（Engineering）等未研究时，攻城锤、投石车造不出来，别让军队在城下干等。
7. **神级科技落后时用间谍偷科技**：把间谍投入「窃取科技」任务，科研投资集中到关键节点，而非全面追赶。
8. **保持科技与文化产出节奏**：每回合科技值约为文化值的 1.25 倍时，尤里卡/鼓舞节奏最佳，避免单线失衡（参考来源见文末）。
9. **被前置卡住时先补尤里卡条件，不要干等**：科技树是严格前置结构，卡住说明前置链没走完，去触发对应尤里卡比空挂科研快。

## L1 核心机制

### 时代结构与科技树
- 全树共 8 个时代：远古（Ancient）→ 古典（Classical）→ 中世纪（Medieval）→ 文艺复兴（Renaissance）→ 工业（Industrial）→ 现代（Modern）→ 原子（Atomic）→ 信息（Information）。
- 每时代约 5~8 项科技，呈树状前置：多数科技要求 1~2 项前置科技，研究本身只受前置树限制（游戏允许「跨时代」研究，不存在时代门槛）。
- 完成科技参与时代推进判定（时代得分），但不影响上述研究规则；「卡时代」通常意味着前置链没走，不是规则禁止。
- 科技与市政（civic）共用同一套成本基数与城市数修正规则，只是走不同的树。

### 四系科技分支（规划视角）
按规划用途，科技树常划分为四线（非游戏内置规则，真实约束是前置树）：
- **军事与扩张线（上部）**：采矿→砌砖→青铜器→骑马……解锁军营、骑兵、攻城与陆军升级。
- **生产力与城市线（中上部）**：畜牧业→轮子→……→工业化……解锁改良、区域与工厂。
- **经济与科研线（中下部）**：灌溉→货币→……解锁商路、银行与学院深化。
- **探索与航海线（下部）**：制陶→写作→占星→帆船……解锁学院（写作）、天文台与海军。

### 尤里卡（Eureka，科技鼓舞）
- 每项科技对应一个尤里卡触发条件（市政对应的激励称「鼓舞」Inspiration），触发后**立即获得该科技研究量的 50%**（一次性、不叠加）。
- 触发在科技完成研究前有效，完成后触发即浪费；研究队列排定前先看触发条件，差一点就完成时先做触发动作再点科技，相当于科研打折 50%。
- 部分政策卡、伟人与文明能力可放大或改变尤里卡收益（如中国的文明能力，原版以 60% 替代 50%，以游戏内为准）。
- 常用触发示例见 L2 数据附录。

### 研究成本：时代基数 × 城市数 × 游戏速度
- 每时代有统一的科技成本基数（标准速度，数值见 L2 表）。
- **每座城市使研究成本 +5%**（标准速度）：修正系数 ≈ 1 + 0.05 ×（城市数 − 1），10 城约 ×1.45（首城是否计入与公式细节以游戏内为准）。
- 游戏速度修正：标准 ×1，快速/史诗/马拉松倍率不同（以游戏内为准）。
- 科研产出主源：人口（每人口约 +0.5 科研）、学院及建筑（图书馆/大学/研究实验室）、学者槽位，以及政策卡、奇观、商路与部分伟人（数值以游戏内为准）。

### 科技胜利前置科技
按 Gathering Storm 规则，科技胜利的关键链（均为项目/区域前置）：
| 科技 | 解锁 |
|---|---|
| 火箭学 Rocketry（现代） | 宇航中心 Spaceport 区域 |
| 卫星 Satellites（原子） | 项目「发射地球卫星」 |
| 登月 Moon Landing（原子） | 项目「登月计划」 |
| 智能材料 Smart Materials（信息） | 项目「火星栖居地」 |
| 纳米技术 Nanotechnology（信息） | 项目「火星水培农场」 |
| 核聚变 Nuclear Fusion（信息） | 项目「火星反应堆」 |
| 预测性网络控制 Predictive Cybernetics（信息） | 最终项目「系外行星远征」 |
- 决策含义：科技胜利的科研段很短，瓶颈在宇航中心产能与项目耗时；提前养一座高产能城，并备好大工程师（见 great-people.md）。

### 特殊科技与关键前置
- **攻城链**：砌砖→攻城锤（Battering Ram）；工程学→投石车（Catapult）；物理学→攻城车（Trebuchet）；化学→臼炮（Bombard）；冶金术→火炮（Artillery）；弹道学→火箭炮（Rocket Artillery）。
- **学院链**：写作→学院与图书馆；教育→大学；化学→研究实验室（以游戏内为准）。
- **核武链**：裂变（Fission）→曼哈顿计划；核聚变（Nuclear Fusion）→热核武器与火星反应堆。
- **海军链**：帆船（Sailing）为海军起点，后续制图学等（以游戏内为准）。

## L2 数据附录

### 各时代科技研究成本基数（标准速度）
| 时代 | 基数 |
|---|---|
| 远古 | 50 |
| 古典 | 175 |
| 中世纪 | 275 |
| 文艺复兴 | 500 |
| 工业 | 750 |
| 现代 | 1250 |
| 原子 | 2250 |
| 信息 | 3750 |
> 注：与市政共用基数；标准速度 ×1，其他速度倍率及含首城与否的公式细节以游戏内为准。

### 尤里卡触发条件示例
| 科技 | 触发条件 |
|---|---|
| 畜牧业 Animal Husbandry | 改良一个牧场（马/牛/羊） |
| 占星术 Astrology | 发现一处自然奇观 |
| 骑马 Horseback Riding | 训练一名骑手 |
| 砌砖 Masonry | 建造一座采石场 |
| 货币 Currency | 建立一条商路 |
| 工程学 Engineering | 在至少两座城市建造城墙（以游戏内为准） |
> 注：触发获得研究量的 50%，单次上限按时代递增（远古约 50 起），具体上限以游戏内为准。

### 其他关键数值
| 项目 | 数值 / 说明 |
|---|---|
| 城市数成本修正 | 标准速度下每城 +5%，10 城约 ×1.45（以游戏内为准） |
| 人口科研 | 每人口约 +0.5 科研（基础值，以游戏内为准） |
| 学院建筑 | 图书馆（写作）、大学（教育）、研究实验室（化学），槽位科研以游戏内为准 |
