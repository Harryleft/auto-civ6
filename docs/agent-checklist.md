# 每局策略检查清单

以获胜为目标开局、续局或推进时使用。开局和恢复续局时读取本清单，后续按下述节奏执行；规则与取舍方法见[获胜决策](agent-strategy.md)，合法操作及回读见[游戏操作](agent-playbook.md)。

同时检查本方获胜路径、对手优势的形成过程，以及本方的响应准备时间。世界排名用于发现差距；胜利进度、先行信号与响应准备时间共同决定紧迫性。

## 六项必查

| 检查项 | 必看内容 | 必须形成的判断 |
| --- | --- | --- |
| 1. 世界排名与能力趋势 | 总分，以及科研、文化、产能、经济、军力、城市规模的排名和差距变化 | 谁在积累优势？差距在哪个环节扩大？需要补强什么？ |
| 2. 本方获胜路径 | 主路线、下一关键里程碑、解锁与建设准备、实际进度和瓶颈 | 当前投入是否推进胜利？需要加速、调整分工或换路吗？ |
| 3. 所有对手的胜利动向 | 本局所有启用胜利路线的当前进度、增长趋势、关键准备和最近突破 | 谁可能率先完成哪种胜利？哪些威胁正在形成？ |
| 4. 应对能力与响应准备时间 | 已有反制力量；解锁、筹资、建设、购买、运输和等待可行动所需时间 | 现在开始准备是否来得及？哪些能力必须提前部署？ |
| 5. 经济与执行基础 | 可支配资源、持续收支、关键城市产能、生产队列、损坏和发展瓶颈 | 计划是否负担得起、做得出来？资源是否投向当前关键任务？ |
| 6. 安全与行动效果 | 城市和单位威胁；战争、外交、议会等状态变化；关键动作后的实际效果 | 原计划是否仍成立？采取行动后风险是否下降？ |

通过 `state overview`、`ranking show` 建立排名和胜利进度，再按本次判断需要读取城市、单位、地图、外交或宗教等领域事实。只使用当前可见或公开信息；未提供的指标保持未知，必要时补查。科技数量、军力或总分排名分别保留其含义，胜利判断使用本局实际胜利条件与进度。

同一决策点可先用 `state decision` 合并读取概览、单位、城市、可见威胁、胜利进度和通知，按 `status`、范围检查及分项状态核对可用事实，再补查会改变选择的信息。需要比较科研、外交、商路或某城生产候选时，使用 `game decision --include ... --city ...`。已有动作确认回执足以支持下一步时直接使用；只有缺少影响判断的事实才补查。入口的范围与限制见[决策事实查询](cli.md#决策事实查询)。

## 各胜利路线的先行信号

逐项检查本局启用的路线，包括本方没有选择的路线。结合已知对手的进展与准备判断风险，未相遇或未公开的信息保留未知。

| 胜利路线 | 提前观察什么 | 提前准备什么 |
| --- | --- | --- |
| 科技 | 科技推进速度、关键科技突破、太空港建设、项目完成与加速能力 | 本方科研和项目城市准备；可行干预手段及到位时间 |
| 文化 | 旅游增长、游客差距变化、关键文化设施与旅游修正 | 本方文化防御、追赶能力，以及可行的外交或其他干预 |
| 宗教 | 传播方向、宗教单位接近、城市压力变化、购买基地改宗风险 | 拦截力量、城市防御余量、宗教单位与资源储备 |
| 征服 | 军队集结、兵种代差、接近首都的路线、已有原始首都控制情况 | 城防、驻军、升级资源和援军到达时间 |
| 外交 | 点数增长来源、下一届议会、竞赛进度、可争夺的得分机会 | 外交支持、合法投票方案，以及竞争得分机会的资源 |
| 分数 | 启用回合上限时的剩余时间、分差及增长速度 | 能在剩余时间内生效的得分投入，或其他获胜路径 |

## 从观察转为准备和行动

根据威胁发展速度与响应准备时间选择状态，从先行信号开始准备。接近胜利门槛属于紧急处置阶段；防御能力应在此前形成。

| 状态 | 判断依据 | 行动要求 |
| --- | --- | --- |
| 持续观察 | 已出现发展信号，尚未形成明确威胁 | 跟踪趋势，识别合法可用方案 |
| 提前准备 | 威胁正在形成，而反制需要较长准备 | 储备资源、解锁能力、部署力量 |
| 主动干预 | 继续等待会压缩可用选择，已有合法有效行动 | 调整资源优先级并执行 |
| 紧急处置 | 对手已接近完成，本方响应窗口很窄 | 优先使用已经就绪、能立即见效的手段 |

响应准备时间按实际依赖关系估计，区分可并行和必须先后完成的步骤；有依据时才估计竞争窗口，并保留估计条件。无法确定对手完成时间时，补查影响判断的关键事实，并比较储备、部署等可逆准备的成本。一次购买、解锁或命令提交，分别按其实际完成阶段记录；防御效果由动作后的事实确认。

## 检查节奏与完成依据

- **开局与恢复续局：**核对世界身份、本局启用的胜利条件及六项基线，确认当前主路线、主要风险和准备缺口。
- **每个已确认的本地可行动回合开始：**更新排名变化、本方里程碑、全部启用胜利路线的新进展与新增威胁，再决定本回合优先级。
- **周期性完整复核：**复核六项，重点检查城市、经济、响应准备时间和资源分配；在任务上下文明确下一次完整复核回合，按游戏速度、阶段和风险调整间隔。
- **关键变化后立即重评：**科技突破、项目完成、军队集结、城市改宗、宣战、议和、议会换届等事件发生后，重查受影响的事实与方案。
- **风险上升时：**逐回合复核对应领域，提前落实反制准备；关键动作后立即读取实际效果，确认风险变化。

检查使用当前世界与回合的事实，并保留上次观测回合及必要变化。已确认、未知、不可见和冲突分别处理；旧快照或读取失败不构成安全依据。回合或动作仍未决时，按[保存与恢复](agent-recovery.md#结果未知)确认原请求。

检查完成后，在现有任务上下文或阶段摘要中保留三项结论：**当前优先目标、需要提前准备的能力、下一步具体行动。** 对异常明确应对措施、所需资源及下一次核验条件，执行后复核效果。沿用现有摘要承载这些结论，无需逐回合重复输出完整清单。

本清单约束模型的查询与决策流程；Runtime 继续负责原生事实、合法执行和结果确认，不增加自动选路、自动干预、后台扫描或新的日记协议。
