# 获胜决策

以获胜为目标开局、续局或调整计划时读取。模型依据规则与当前事实取舍；Runtime 提供查询、提交和确认，合法执行见[游戏操作](agent-playbook.md)。

## 区分三类信息

| 信息 | 内容 | 何时更新 |
| --- | --- | --- |
| 稳定规则与身份 | 本局配置、文明和领袖身份、能力定义、解锁关系与胜利条件；对手使用同一套资料 | 开局或相遇时识别；加载、配置改变或证据冲突时复核适用性 |
| 动态事实 | 地图可见信息、城市、资源、产出、军力、关系、已解锁内容和胜利进度；能力当前的生效条件 | 决策前刷新会影响选择的部分，动作后回读 |
| 可修正判断 | 主路线、备选、瓶颈、对手意图、预期收益与竞争窗口 | 新证据改变收益、风险或可行性时调整 |

能力定义稳定，不代表条件已经满足或收益始终相同。知识目录覆盖的文明和内容不证明本局存在、已购买或启用。对手能力不能代替其当前意图；未知信息保留未知。

## 开局与相遇

1. 用 `get_game_overview` 核对回合、速度、难度及本方 `civilization_type`、`leader_type`；规则与地图设置核对[基准说明](../fixtures/saves/README.md)。身份字段缺失时保留未知，不从显示名猜内部 ID。
2. 按[知识 MCP 查询](../civ6_knowledge/README.md#mcp-查询)，在 `civilizations` 主题用确认的文明和领袖 ID 定位条目，先读摘要确认身份，再读能力规则、条件、限制和专属内容关联；来源冲突时展开证据。查询契约与读取层次以该入口为准。
3. 用 `get_cities`、`get_units`、`get_strategic_map` 和 `get_victory_progress` 建立当前局面与启用胜利的基线；结合地图、资源、文明能力和竞争情况形成初步路线。
4. 用 `get_diplomacy` 识别已相遇对手的 `civilization_type`、`leader_type`，按同一知识入口理解其能力。未相遇对手保持未知；公开身份缺失时不推断。

稳定规则已足够支持当前判断时直接使用；需要补充某项机制时按需展开，无需每回合重读整套资料。

## 决策与调整

每次有意义的选择围绕以下问题组织，不要求额外表单或固定记录格式：

1. **目标与瓶颈**：当前要解决什么，什么限制了路线完成？从本局启用的胜利中比较主路线与可行备选，文明优势作为收益依据，不固定分配胜利路线。
2. **机制与事实**：哪些能力、解锁或通用规则影响选择？哪些条件仍需查询？区分未解锁、已解锁、可执行、正在执行、已完成和未知，不能用积分或成本代替完成与合法性证据。
3. **候选与取舍**：比较候选行动的收益、一次性花费、持续收支、见效时间和风险；改良还需比较市民换岗损益。单位是否移动取决于全局目标、地形、威胁与保持位置的收益，剩余移动力不构成移动理由；旧移动意图不再合适时明确取消，再选择驻防、治疗或待命。将扩张与现有城市建设、研究、外交、军备及竞争响应放在同一比较中；核对土地、可达性、护卫、援军到达时间、未知邻城风险和落城收益，不让连续补建筑隐式排除扩张，也不让扩张成为无条件指令。
4. **执行与回读**：选择能推进目标的合法行动，使用本回合事实执行，回读生效状态和收支变化；未知结果按[保存与恢复](agent-recovery.md#结果未知)处理。
5. **修正判断**：比较实际结果与预期，更新下一行动。新城、战争、关键解锁、对手进度变化或计划失效时重新评估主路线、瓶颈、竞争窗口和备选。

对手风险依据 `get_victory_progress` 与必要领域事实判断，只比较本局启用的胜利；按进度变化、风险和响应所需时间决定复核频率。推进报告的轻量预警只提供线索，读取失败或没有提示不能证明安全。保留原始进度与需求；估计窗口和风险比例属于可修正判断。

路线赶不上竞争窗口时，比较加速、换路和干预的合法能力、代价及见效时间，再选择响应并核对效果。仅消耗本方发展而不能改变竞争局面的行动，需要重新评估。

在任务上下文或本轮摘要保留当前目标、下一瓶颈、主要风险和下一行动即可；不新增缓存、后台观测、强制反思或每回合日记。

## 验证与边界

新实机测试从 `benchmark_turn_1` 原件开始，按任务要求保存检查点；保存与恢复遵循[保存与恢复](agent-recovery.md)，保留旧成果。战略失误不作为回档挑选结果的理由。

获胜证明使用普通工具策略动作与原生终局。不得直接修改资源、产出、科技、胜利状态或地图制造胜利；本轮避用既有非标准晋升兼容路径。启发式、分数领先和提交成功均不代替原生胜利；失败也保留结果与原因。
