# 获胜决策

以获胜为目标开局、续局或调整路线时读取。模型负责取舍；Runtime 提供事实、提交与确认，动作按[游戏操作](agent-playbook.md)执行。

## 开局与当前计划

1. 用 `get_game_overview` 核对文明、速度、难度和回合；规则与地图设置核对[基准说明](../fixtures/saves/README.md)，缺失信息保留未知。用 `get_cities`、`get_units`、`get_strategic_map` 核对经济、探索和安全。
2. 用 `get_victory_progress` 建立初始全局基线，结合 `get_diplomacy` 区分本方、已相遇对手与未知信息；只使用工具允许读取的事实。
3. 在任务上下文或本轮摘要保留：**主路线、备选、下一瓶颈、扩张动作、领先对手与风险、下一行动**。在新城、战争、关键解锁、对手进度突变或原计划失效时更新，无需每回合写日记。

扩张、研究解锁、区域落位、议会或胜利机制不清楚时，按[知识 MCP 查询](../civ6_knowledge/README.md#mcp-查询)搜索并展开规则，再用对应游戏工具核对当前候选、费用和进度。已有规则足够支持判断时直接行动，无需每回合重查。

## 扩张优先

开局即评估下一座城。新增城市的产出会持续累积；安全扩张窗口有限时，将开拓者与护卫同当前建筑、奇观或军备比较，而不是等现有城市建设完毕。

| 决策 | 必要核对 | 行动依据 |
| --- | --- | --- |
| 地点 | `get_global_settle_advisor`，再用 `get_map_area` 核对候选 | 淡水、有效粮锤、资源、区域空间、忠诚与邻国边界；推荐分数不能替代判断 |
| 通路与护卫 | `get_units`、`get_pathing_estimate`；已有开拓者时可用 `get_settle_advisor` | 先探索路线与危险点，安排实际可到达的护卫，避免裸奔或长期闲置 |
| 时机与成本 | `get_city_production`、人口、财政和防御缺口 | 比较生产或购买成本、落城时间及何时回本；有安全收益时明确安排下一名开拓者 |
| 阶段规模 | 按当前速度、可用土地和对手城市规模设置本局阶段城数目标 | 目标是可调整的策略，不是游戏规则；落后时先查土地、安全、忠诚或生产瓶颈 |

没有安全候选时，先补探索、护卫或外交条件，再复核扩张。城市完成生产后重新比较扩张机会，不让连续补建筑默认替代扩张。战争先保住核心；战后重新安排扩张和发展，并核对战争是否获得了城市、资源或时间收益。

## 胜利路线与回报期限

从本局启用的胜利中选择一条主路线和可实现的备选。比较文明能力、土地与区域、现有解锁、生产能力和对手进度。

| 安排 | 决策要求 |
| --- | --- |
| 下一瓶颈 | 指明缺少的科技、市政、区域、项目、资源或胜利点，以及解除瓶颈的下一步 |
| 科研与市政 | 优先解锁能解除瓶颈的内容；评估尤里卡、鼓舞和绕路的实际节省 |
| 生产与政策 | 比较收益何时生效，能否赶在预计竞争窗口前回本；保留必要的生存投入 |
| 交易与外交 | 围绕关键资源、现金、研究与安全窗口安排；关系成立后回读确认 |
| 世界议会 | 按本次效果、胜利点、对手竞争与共同预算分配票；会后核对结果与点数变化 |

区分未解锁、已解锁、可生产、正在生产、已完成和未知。积分不能证明项目已完成，生产成本不能证明当前可建；缺失事实先查询。对手窗口只是基于当前证据的估计，不当作精确剩余回合。

主路线已无法及时完成时，明确选择加速、换路或干预领先者，再调整研究与生产。干预需比较间谍、外交、议会和军事的合法能力、见效时间与代价，避免只消耗本方发展却不能延缓对手。

## 对手预警与响应

- 建立初始胜利基线后，在扩张、战争、关键解锁和领先者变化时复核 `get_victory_progress`。只读预警不会替模型选择行动。
- 已确认推进后的报告附带轻量胜利风险；读取失败保留未知，并补查必要事实。没有提示不能单独证明安全。
- 对手已有宇航中心或实际太空进度时，每回合核对必要胜利事实；结合科研、生产及项目状态判断加速与干预。保留原始进度和需求，包括小数，风险比例仅是策略启发式。
- 外交胜利点接近需求、游客比例上升或宗教扩张时，读取对应路线事实；禁用胜利不列为竞争风险，未相遇对手的缺失信息不补猜。
- 风险上升后，先比较本方完成路线和对手进度，再执行一个明确的响应并回读；下一次确认推进后核对响应是否改变了瓶颈。

## 验证与边界

本轮新局从 `benchmark_turn_1` 原件开始，按任务要求保存检查点；保存与故障恢复遵循[保存与恢复](agent-recovery.md)，保留旧成果。战略失误不作为回档挑选结果的理由。

获胜证明使用普通工具策略动作与原生终局。不得直接修改资源、产出、科技、胜利状态或地图制造胜利；本轮避用既有非标准晋升兼容路径。启发式、分数领先和提交成功均不代替原生胜利；失败也保留结果与原因。
