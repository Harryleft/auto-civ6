## 补记（2026-10-25 复核）

发布后复核发现两处客户端配置残留，已清理；上表保留当时的检查结果，不改写原记录：

- 版本库内 `.gemini/settings.json` 仍注册 `civ6-mcp`，任何在该目录启动的 Gemini CLI 都会直接暴露 MCP 工具。已清空为 `{"mcpServers": {}}`；原 registrations 只覆盖 Codex／Claude／Pi，未包含 Gemini，已补充说明。
- 本机（gitignored）`.claude/settings.local.json` 的 `enableAllProjectMcpServers` 仍为 `true`，与“Claude 项目自动批准项移除”不一致；已置为 `false`。

同轮还清理了其余直接 MCP 入口表述：`docs/windows.md` 改为 CLI 启动并在启动 shell 中注入环境变量；热座规格的模型入口统一为 `civ6 debug --hotseat-seat/--hotseat-run`（`scripts/hotseat_agent.py` 降为 CLI 内部控制器）；旧协调器 `scripts/hotseat_endurance.py` 标记为 legacy，需显式 `--acknowledge-legacy-mcp` 才能运行，未迁移到 CLI，仅供复现历史实验。
