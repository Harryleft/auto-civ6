## 验收前发现与修复

首版 `97a84fe` 的第一次换档在0.00669秒返回 `Error: Native frontend state unavailable; no exit sent.`，未提交退出或加载，PID和第50回合保持不变。紧邻的原生只读查询确认仍在对局。旧实现强制重新发现目录时关闭已有连接，发现过程的短暂 `OSError` 会直接变成未知；旧日志未记录具体 errno。

修复 `052786b` 只在前端只读发现／查询阶段，对 `OSError` 按0.2秒间隔在原有超时预算内重试；取消仍向上传播，退出和加载不重放。补充离线测试后，以 `23bb554` 从未改变的第50回合重新开始全部正式比较。早期拒绝保留在原始日志和 `precount-discovery.json`，未计入修复版30次成绩。
