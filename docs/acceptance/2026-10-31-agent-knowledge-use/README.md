# 五个盲智能体的知识利用验证

结论：这次离线试验中，智能体确实利用了仓库知识。获得资料的三个智能体都访问了现有操作文档、AGENTS、源码和脚本，并将其中的特定契约写进答案。两名仅使用 CLI 的对照也利用了 CLI 帮助和规则查询，并非「没有知识」。额外仓库资料组的细节覆盖更完整，但本试验没有证明总读取成本下降、实际游戏执行更可靠或胜率提高。

本轮没有运行真实游戏。所有 CLI 都为 `debug --offline`，实际 RPC 仅涉及静态知识或 Runtime 内存状态；没有原生游戏查询、变更、加载或推进。先前 T100 核验存档的 SHA 仍为 `7ceb1ee55c00412f2ca3a3b3956fc05b043cb8e8002de98e7882c783f693115c`。

## 设计与盲法

- 源版本固定为 `8c373f85ba9034f6ce1d6d9e00a7a1ff4608dd90`。先冻结题目、分组、48 分评分条件、公共提示词和访问网关，再启动五个 `fork_turns=none` 智能体；均继承宿主模型设置，没有模型覆盖。
- 随机分为两名对照、三名实验。对照获得题干、最小操作边界及当前离线 CLI；实验额外获得该提交的 268 份仓库材料，共 85,291,311 字节，包括 AGENTS、文档、CLI 实现、知识文件和脚本。未提供父对话、旧局总结、分组标签或评分答案。
- 五者处理完全相同的 12 题，覆盖原生政策条件、队列、交易尾部、未知结果、政府窗口、晋升、逐城宗教、升级、战斗预估、收益来源、邻城传教和检查点／脚本边界。题干给出必要的历史观察，不允许实时查询补全。
- 每名上限为 20 次材料访问、2 个离线 CLI 会话、40 条会话命令。受宿主并发限制先启动三名，再在空位释放后启动两名；没有向后批次提供前批次结果或改变指令。
- 材料访问通过同一无策略网关记录路径、范围、输出字节和 SHA；CLI 保留自身原始日志。评分按每题四项二值条件判断实际内容，引用数量不加分。全部答案完成后固定评分，再读取分组映射。

这是任务信息盲测，不是严格双盲实验：参与者能从文件是否存在推测访问条件；宿主强制指令、预训练知识无法清除，评分者也可能从引用推测分组。访问限制依靠指令和网关，不是操作系统沙箱；网关记录不能排除未披露的越界访问。因此不把它表述为完全无知识对照或严格隔离的因果证明。

## 利用方式仍有成本和缺口

显式访问顺序并不是先读 AGENTS 再按路由展开。三名实验者都先大段读取 CLI 文档，之后才显式读取 AGENTS。宿主可能已经注入部分指令，所以只能评价网关记录中的显式访问，不能认定它们启动时从未见过 AGENTS。

三者均请求了 CLI 文档第 1～501 行，随后又请求第 156～358 行或第 170～358 行；后一次单独生成 28,922～29,782 字节重复区间。完整材料操作共生成 164,645～169,600 字节；对照每名为 7,292 字节，但其 CLI 帮助调用更多。这些是工具产出的字节，不能证明每一字节均被模型看见；工具截断也可能使再次读取有必要。CLI 正文与原始 JSONL 是另一种口径，不能直接相加成 token 或宣称总读取量节省。

实验组平均材料操作 14.33 次、CLI 命令 3 次；对照分别为 4 次和 37.5 次。它们表现为「多读文档、少探索命令」与「少读文档、多用 CLI」的交换，尚没有整体验证证明哪种总成本更低。七个离线会话均正常关闭，没有 CLI 命令错误或工具错误；部分首次非 TTY 启动在零业务命令时 EOF，增加了启动成本，没有导致游戏请求或未决状态丢失。

实验组仍遗漏恢复后的 pending 核对，p36 的预估验证也未覆盖 pending。另有一份答案进一步建议移除测试脚本；本题没有验证该脚本应删除，也没有删除材料。更完整的来源并不保证每个结论或后续动作均正确。

## 下一步优先级

1. 先改窄命令的可发现性：让 `city list --help` 明确逐城宗教字段，让 `map area --help` 明确来源、精度、零与 unknown。复用现有事实定义，避免再新增一份重复的大手册。对照在这两题的具体缺口支持这个优先级；真实查询输出中的说明可能已经缓解问题，仍需后续实际调用复验。
2. 减少整份 CLI 文档读取：入口应方便定位命令组和对应小节，再按需展开；不要把「必须多读文档」当作目标。本次已观察到整篇加重复区间的输出成本，尚未证明更窄入口的收益。
3. 把验证条件贴近动作入口：保留当前政府的 ACK、普通查询可顺带确认原动作、恢复后的 pending 核对，应在相关帮助与操作段中容易找到。后续验证应看实际单次提交与确认，不只重做问答。

本轮只评估并记录结果，没有修改生产策略、规则知识或 Runtime 行为，也没有运行通用对局脚本。不能把上述建议写成已验证修复。
