## 失败分类与机制

| 问题 | 证据 | 影响与后续处理 |
| --- | --- | --- |
| 中文检出目录的 editable 安装失效 | `.pth` 的 UTF-8 路径实际存在；CPython 3.12.2 的 `Lib/site.py:184` 以 `encoding="locale"` 读取，同一字节按 cp936 解码后变成不存在的「楠屾敹」路径。`PYTHONUTF8=1` 时仍无法导入 `civ_mcp`，帮助命令也报 `ModuleNotFoundError` | 当前已验证的规避方式为完整路径只含 ASCII 的检出；安装器／Python 版本方案仍需单独修复验收。不能将可用的中文日志参数等同于可用的中文安装路径 |
| UU 交互终端 Ctrl+C 后退出 | 离线会话就绪并成功读取 pending 后，按 Ctrl+C；终端打印两次 `Session retained`，随后出现 `session_closing(reason=quit)`，但 JSONL 中没有 `quit` 命令。下一条 `pending` 被 PowerShell 当作 shell 命令处理 | 在这条 Windows／UU 终端链路上，会话保留承诺未成立；仅验证了空闲且没有 pending 的离线会话。输入读取把空字符串送入正常退出路径，具体信号／EOF 传播还需修复验证 |
| 证据 JSON 的源码路径键不统一，触发 14 项失败 | Windows 的 `context.source_sha256` 使用 `src\\civ_mcp\\cli.py`，测试及跨平台消费者按 `src/civ_mcp/cli.py` 取值，出现 `KeyError` | 当前命令本身多已完成，失败发生在证据契约核对；应统一相对路径的序列化格式，再在 Windows 重跑相关 CLI 测试 |
| Unix socket 转接器，2 项失败 | 本机 Python 没有 `socket.AF_UNIX`，`scripts/civ6_cli_relay.py:84` 抛 `AttributeError` | Windows 上该共享 CLI 转接器不可用；需要明确平台边界或增加独立验证过的 Windows 传输实现，不能据此宣称普通前台 CLI 不可用 |
| 既有热座控制器，1 项失败 | 原控制器 `scripts/hotseat_agent.py` 导入 `fcntl`；Windows 子进程在 MCP 初始化阶段关闭连接 | 原生双人热座属于既有 macOS 补丁实验，本轮没有为 Windows 移植控制器或验证席位交接 |
| 系统命令编码，1 项失败 | `tasklist` 的无匹配提示为 cp936；在 `PYTHONUTF8=1` 的测试中按 UTF-8 解码，reader thread 抛 `UnicodeDecodeError`，`stdout` 变成 None | 失败在超时测试的系统进程回读；此前的有界超时、单次启动和直接子进程回收断言已通过。应按系统命令实际编码读取或避免解析本地化文字，再核对实际解释器 PID |
| Windows 夹具关停回执，2 项失败 | `test_timeout_retains_process...` 和 `test_later_read_timeout...` 取不到 `engine['submissions']`；夹具只在 `disconnect` 写出这些最终字段 | 缺少最终回执不能解释为没有提交；需核实 Windows 子进程终止与 lifespan 收尾时序，建立可靠的测试见证 |
| 跨平台既有夹具失配，1 项失败 | `test_real_pending_owner...` 在 macOS 同提交也失败。新增 `on_confirmation=` 关键字后，`fake_debug_server.units()` 仍不接受参数，实际观察列表为空 | 这是既有测试夹具失配，不是 Windows 独有回归；更新替身签名后仍须保留单次提交、原 owner 与确认行为断言 |

后六行中的测试失败数为 `14+2+1+1+2+1=21`。中文安装和 Ctrl+C 是额外的手工验收失败，不混入这 676 项统计。macOS 对照只运行 debug 的前三项失败及热座预演共 4 项，结果为 1 失败、3 通过，耗时 14.87 秒；不能据此代表 macOS 全量结果。

## 复现入口

从英文路径检出执行：

```powershell
$env:PYTHONUTF8 = '1'
uv sync --locked
uv run --locked civ6 doctor
uv run --locked civ6 verify knowledge
uv run --locked civ6 test debug --timeout 300
uv run --locked civ6 test knowledge --timeout 300
uv run --locked pytest -q tests/test_windows_compatibility.py tests/test_dev_cli.py tests/test_cli_capabilities.py tests/test_cli_relay.py tests/test_game_launcher.py tests/test_codex_hooks.py
```

中文安装问题的最小入口是在相同 Windows／Python／locale 环境的新中文目录执行 `uv sync --locked` 后运行 `uv run --locked civ6 --help --json`。不要通过改写 `.pth`、指纹或放宽检出身份检查，把一次诊断变成无记录的修复。

Ctrl+C 问题使用新的 `debug --offline`，在输入 `pending` 并得到回读后按 Ctrl+C。保留 `debug.jsonl` 和终端输出，核对有无显式 `quit` 命令以及 owner 是否仍存在；不要在承载真实未决请求的会话中复现。
