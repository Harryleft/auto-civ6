# 城市产出偏好与真实确认

## Problem Statement

本轮 T136 调用粮食偏好后，西巴尔仍反复在 7／8 人口间饥饿波动。核对本机官方 CityPanel：SET_FOCUS 的 PARAM_FLAGS 为 0 表示偏好、1 表示忽略，PARAM_DATA0 为 1／0 表示设置／清除；现有实现将标志写反且遗漏目标状态，提交后立即报告成功，没有确认最终偏好。

## Solution

修正现有 `set_city_focus`，将模型指定的偏好作为目标状态，通过原生标志执行并回读确认。已经满足目标时不重复切换；结果未知保留门禁，不把提交或陈旧读取叙述成完成。

## User Stories

1. 玩家设置粮食偏好后，能确认粮食实际被偏好，而非被忽略。
2. 玩家重复同一请求时不会把正确偏好切掉。
3. 玩家从被忽略的产出切换到偏好时，原生状态最终一致。
4. 玩家使用 default 时清除已有偏好与忽略，并确认实际中立。
5. 玩家在迟到、取消或丢回应后重复调用只确认原尝试，不重放切换。
6. 玩家收到的产出变化仍由原生市民分配决定；工具不保证粮食一定增加或永不饥饿。

## Implementation Decisions

- 依据本机原始 CityPanel 及实际 Expansion2 覆盖确认命令标志与显式设置／清除状态，不修改游戏规则或直接分配资源。
- 保留公开工具及参数，使用目标状态比较，明确无变化、已确认、零提交拒绝及结果未知；按原有语义清除其他偏好，并处理目标被忽略的情况。
- 复用现有动作生命周期及城市实体门禁；原子提交前核对原世界、城市与原偏好，提交块至多进入一次。提交后通过真实 Citizens 偏好回读确认，跨世界、缺失读取及超时保留未决，不自动恢复。
- 不增加固定市民分配策略或新后台机制。

## Testing Decisions

沿用已确认的 GameState／FakeConn、Lua 5.1 与 MCP 公开边界；TDD 覆盖官方标志、已满足目标、被忽略目标、default、延迟／丢回应／取消、世界／城市变化和保存推进门禁。只运行受影响模块。实机在当前 T141 同轮状态设置粮食偏好，回读 Citizens 及城市产出；不为改善战略结果回档。

## Out of Scope

自动市民分配、锁定地块、保证城市不饥饿、其他政策／交易改造、全量测试、push。
