# CLI 领域能力补齐

目标：通过同一前台 civ6 debug 会话完成领域查询与显式操作，新增数据均为 JSON。原生规则决定资格；不新增自动策略、后台观测或操作重发。当前 T16 仅做只读实机核验，付费、任命、政体、信条等操作用隔离测试覆盖，不为验收消费本局资源。

## 初始能力核对

| 能力 | 本次开始前状态 | 补齐内容 |
| --- | --- | --- |
| 科技／市政进度、选取目标 | research show/set 已有 | 独立 technology/civic 命令组 |
| 科技／市政搜索与收益／解锁过滤 | knowledge 仅名称／ID 搜索；无收益过滤 | 按食物、科技、生产、文化、金币、信仰、住房、单位、改良、奇观检索，返回匹配依据 |

## 阶段

- [x] 阶段一：补齐已有领域能力的命名 CLI 入口，隔离验证参数与预演。
- [x] 阶段二：科技／市政静态搜索及多条件过滤，验证知识指纹、匹配证据、分页和不连接游戏。
- [x] 阶段三：气候、历史、伟人历史、小道消息、全球资源和地图搜索的原生只读查询。
- [x] 阶段四：文档、定向回归、同一 CLI 的实机只读验收与限制清单。

所有未获原生依据的字段返回 unknown／null，不能用空列表或零代替。静态检索不验证本局 DLC／模组、文明所有权或当前解锁资格。原生历史没有提供历史付款方式时，不从人物成本反推金币／信仰支出。

## 交付与验证

命名领域子命令从 43 个增至 76 个，保留已有入口。新增两个只读 MCP：`search_research`、`get_public_report`。搜索可离线执行；原生查询沿用同一 CLI／Runtime，不打开游戏面板，不触发选择或清除未决请求。操作别名复用既有 GameState 的提交、确认和资格检查，不另建操作通道。

| 当前能力 | CLI 入口 | 本轮验收 |
| --- | --- | --- |
| 科技／市政进度、选取、搜索、10 类过滤 | `technology status/set/search`、`civic status/set/search` | 实机读进度，离线查匹配依据、多条件、分页和指纹；选择逻辑隔离回归 |
| 当前政体、可用政体、政策及变更 | `government show/list/change`、`policy show/set` | 实机酋邦／政策回读；变更、资格、丢回应确认隔离回归 |
| 万神殿、信条、宗教状态 | `religion pantheon/choose-pantheon/beliefs/show` | 实机查询；选择与信仰扣费的单次提交隔离回归。万神殿是满足条件后选择信条，不是建造建筑 |
| 伟人候选、点数领取、金币／信仰赞助、过去招募 | `great-person list/recruit/buy/history/reject` | 实机候选与历史查询；付费确认隔离回归和两币种预演 |
| 气候概览、碳排放、事件 | `climate show/history` | 实机概览及已知空历史；非空事件、分页、隐藏地点与缺失接口隔离验证 |
| 本方历史年表 | `history show` | 实机返回两条历史时刻，含回合、时代得分与描述 |
| 总督任命、调派、升级 | `governor list/appoint/assign/promote` | 实机列表；既有动作确认及目标归属隔离回归 |
| 科技／文化／信仰／金币每回合产出、外交支持、使者 | `empire show` | 实机 JSON 数值回读 |
| 帝国资源、城市、小道消息 | `empire resources/cities/gossip` | 实机查询；本局可见小道消息为空 |
| 已相遇文明身份、文明及领袖能力 | `civilization list/show/abilities` | 本局尚未遇到其他主要文明；实机查本方身份和关联规则，已相遇／未相遇门禁隔离验证 |
| 全球资源界面 | `resources global` | 实机查询为空；隔离验证外国可交易量来源，禁止读取外国原始库存 |
| 时代得分、城邦、使者、世界排名 | `era show`、`city-state list/envoy`、`ranking show` | 实机只读入口；派遣使者隔离回归及预演 |
| 资源、奢侈品、战略资源、历史古迹、村庄定位 | `map search resource/luxury/strategic/antiquity/village` | 实机得到 4 处奢侈资源、3 处战略资源；古迹／村庄为空；迷雾、资源识别和动态地点隔离验证 |

科技／市政过滤依据是静态快照中的解锁关系和已捕获的正向收益、住房关联，返回 `match_evidence`。条件修正、文明专属、模式和当前游戏资格不在搜索时计算，不能将标签直接当成本局立即收益。全局资源是自有库存和已相遇文明可交易量，不是全图未揭示资源总量。历史付款币种／实际金额、物理 ppm 浓度仍无可核验的原生来源。

691 项定向测试通过；四次顺序的前台 CLI 只读会话共 47 次工具调用，无错误、无 pending，退出均正常。另一个离线会话执行 2 次搜索、8 次操作预演，全程未连接游戏。当前局面保持苏美尔 T16、种子 −1896272000，原始基准指纹未变；本轮未在实机消费资源或更换政策／政体。非空伟人招募史、气候事件、小道消息及遇到其他主要文明后的结果仍待对应实机局面验收。

命令与参数见 [CLI 手册](../../cli.md#科技市政和新增领域命令)，过程及 JSON 明细见 [只读验收记录](../../../games/2026-10-25-cli-capabilities/runs/20261025-090147/README.md)。原生字段依据本机 `ClimateScreen.lua`、`GreatPeoplePopup.lua`、`HistoricMoments.lua`、`ReportScreen.lua`、`GlobalResourcePopup.lua` 和政体面板的 getter，具体来源及限制随验收记录保留。
