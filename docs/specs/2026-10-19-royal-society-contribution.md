# 皇家学会：单次贡献与异步确认

状态：贡献修复已验收；整轮终局验证继续。沿用当前集成分支；工作项见[本地 tracker](2026-10-19-royal-society-contribution-tickets.md)。

## Problem Statement

本轮 T189 已建成皇家学会，登月项目进行中，第一名 6 次劳动力建造者已到宇航中心。现有贡献工具在第一次请求后立即读取劳动力，未变化便再提交空参数请求，随后尝试 `RequestCommandImmediate`。异步执行时，这会把“尚未确认”误当作失败并重放不可逆动作，也可能访问已经移除的单位。

此次先通过代码发现风险，尚未调用贡献工具；不以实机重复消耗验证缺陷。

## Solution

保留 `unit_action(action="sacrifice_charges")` 入口。一次明确意图只提交一次标准原生命令，随后读取本次动作的原生见证，确认建造者劳动力消耗及对应项目收益。未知时保留未决门禁，重复同一调用只确认原请求。

## User Stories

1. 作为游戏 Agent，我要在皇家学会存在、建造者和项目资格已核实时贡献劳动力，以加快选定项目。
2. 作为游戏 Agent，我要绑定完整单位身份、城市、区域、项目、回合和世界，以免旧 ID 操作新单位或新对局。
3. 作为游戏 Agent，我要每次意图最多提交一次原生命令，以免延迟、超时或重复调用造成重放。
4. 作为游戏 Agent，我要区分命令返回、劳动力消耗和项目收益，以免把提交成功当作完成。
5. 作为游戏 Agent，我要在单位立即移除时仍能依据本次原生见证确认，以免正常消耗卡住流程。
6. 作为游戏 Agent，我要区分贡献、外部移除和无效旧帧，以免凭单位消失推断项目已获益。
7. 作为游戏 Agent，我要在贡献恰好完成项目时确认对应完成，而非要求队列继续保留该项目。
8. 作为游戏 Agent，我要在未知时只读核对并保持门禁，以免后续移动、推进或其他消耗越过未决动作。
9. 作为游戏 Agent，我要让无资格、同城当回合已贡献、身份不符及缺失必要能力在提交前拒绝。
10. 作为维护者，我要复用现有动作生命周期和离线边界，避免新增游戏控制实现或自动决策。

## Implementation Decisions

- 使用现有 ActionLifecycle 归属准备、单次提交、确认、取消和未知门禁；策略、单位移动、项目选择及后续贡献仍由模型明确调用。
- 准备阶段核对本方完整建造者 ID、剩余劳动力和移动力、皇家学会、所在自有区域、对应城市当前项目及原生资格。不能以同索引、另一座区域或另一项目满足身份。
- 仅调用一次标准 `RequestCommand`。删除空参数重试和 Immediate 回退；原生拒绝、调用进入后异常、取消和响应丢失分别处理。
- 提交前安装本次 token 与世界、回合、完整单位及目标绑定的原生见证；复用已有安全观察模式。不能依赖单位移除后继续访问旧 userdata。
- `UnitChargesChanged` 的原始数值不直接等同剩余劳动力。T191 皇家贡献实测原始值 6→12，随后移除，最后才到达匹配命令事件；普通农田则为 6→5。缓存事件而不预设到达顺序：现存单位须核对实际剩余减少量；皇家贡献移除须核对单次原始变化幅度等于准备时全部剩余量，且精确命令、移除、身份与项目效果均匹配。缺少任何见证仍未知，不用贡献公式反推。
- 完成证据须同时支持本次劳动力消耗及绑定项目进展或完成。项目进度使用已存在的 `GetProjectProgress`／`GetProjectCost` 读取；完成可用精确匹配的原生项目完成事件或适用的完成计数变化。空队列和旧单位消失都不能独立证明完成。
- 延迟旧帧、读取错误、原生返回见证缺失、单独移除、世界／回合／目标变化不能解锁。丢失通信响应但原生缓存仍保存完整匹配见证时，允许后续只读确认。
- 确认过程中不得再次提交。其他意图仍受门禁约束，显式恢复沿用现有入口，不自动读档或重启。
- MCP 调度允许同一贡献请求的确认，不允许将其他动作当作确认。展示实际观察到的贡献与效果，不预设每次收益或消费一定相同。

## Testing Decisions

沿用用户已确认的 GameState／FakeConn、内存 MCP、Lua 5.1 和临时目录边界，不访问游戏。以公共 GameState／MCP 入口和执行的 Lua 可观察行为为主，复用既有消耗后移除及未知门禁测试模式。

覆盖：延迟生效只提交一次；重复确认不重发；立即移除；进度增长；项目完成与队列清空；正常返回见证丢失与通信响应丢失；移除事件不匹配、提交前事件、旧代单位、错误所有者、不同项目／世界／回合；取消与异常；原生资格拒绝；未知阻止后续写入；重复已消耗单位不操作复用索引。只运行直接相关模块及必要编译、差分检查，不跑全量。

## Out of Scope

其他命令的全面迁移、自动贡献循环、自动移动、自动选项目、改动皇家学会数值、资源或胜利状态、即时执行兼容路径、战略回档、push 或合并 main。
