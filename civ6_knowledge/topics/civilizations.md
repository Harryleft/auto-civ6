# 文明与领袖

查询契约见 [知识入口](../README.md#查询)。使用 `civilizations` 主题按本方或已相遇对手的文明、领袖内部 ID 查询；同名或变体保留独立 ID。

先用 `summary` 确认身份与来源范围，再读 `rule` 的文明／领袖对应、直接与继承能力、专属内容和替代／解锁条件；效果与条件保留原始 Modifier 关联。冲突或缺失时展开 `evidence`，不从名称推断缺少的能力。

`local_cached_rules_snapshot` 是缓存定义；`installed_definition_catalog` 是缓存缺少身份的安装目录补充。后者展示原始包内关联与条件，`applied=false`，并列出 SQL／缺失目标等覆盖缺口；继承的缓存引用标为 `cached_reference_only`，没有合并成有效规则。需核对领袖能力时读取对应领袖及 Trait 卡，文明卡不替代领袖卡。

文明卡列出可用领袖，不把各领袖能力合并为文明共同能力。能力定义不证明当前生效，也不证明资料片拥有或启用；资料中的其他文明不等于本局对手。对手隐藏议程、意图和战争计划保持未知。
