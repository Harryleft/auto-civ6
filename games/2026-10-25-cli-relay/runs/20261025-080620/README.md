已完成：实际 Codex CLI 控制苏美尔，T1 净推进 10 回合至 T11；实际 Claude Code CLI 接手同一局面，净推进 5 回合至 T16。两阶段通过同一个 `civ6 debug`／MCP 会话执行项目 CLI 命令；没有直接游戏 MCP 调用、热座席位改造或后台观测服务。最终保存和只读核验通过，游戏保留 T16，CLI 正常退出且无未决上下文。

本次是单文明先后接力，不是多个文明同时参与的验证。基准为 `fixtures/saves/benchmark_gold_tun_1.Civ6Save`：神级、快速、极小四叶草、苏美尔／吉尔伽美什，种子 −1896272000。原件 SHA-256 `0d25d557e68b0efbd1aed7e66de9b8434f3a9ac9d321291d45cbe9df83fe3abf`，项目原件、Single 原件及本轮副本均未改变；启动的是未修改的 Steam 原版引擎。上一局双 AI 成果及存档保持原样。

## 实际问题与处理

- 首次自制转接器把 `verify state` 的内部工具结果当成整条命令结束，后续只读回读发生错位。Codex 在执行任何游戏动作前停止于 T1。旧 CLI 明确 quit 且 PASS、无 pending；只结束已关闭 CLI 的转接进程，保留原始证据，修复命令边界后显式建立新 CLI，游戏未重载或回档。修复后的同一会话贯穿完整接力。另有一次 Codex resume 参数不兼容导致零执行退出，改用配置参数后继续，失败日志保留。
- T8 勇士移动到一半遇到自然奇观信息界面，返回未知。模型曾尝试结束回合，被原动作门禁正确阻止；读取 pending、单位、状态后定位 NaturalWonderPopup，经 CLI 显式关闭信息界面。原单位随后到达目标，查询确认原 pending 已消除，再推进 T8→T9；没有重发该移动或通过新服务绕过门禁。
- T11 保存被科技完成弹窗明确阻止，未发送保存；关闭信息弹窗后同名首次实际保存完成。Claude 的一次攻击和一次移动因原生路径不成立零提交拒绝，读取新状态后调整行动。
- 部分原生官方分数与分类合计不一致，CLI 已在回读中显示；未改分或将分类合计当成官方分数。

## 信息弹窗与外交的边界

本轮实际验证的是自然奇观、科技完成等信息界面。真实外交／首次接触／谴责会话需 `get_pending_diplomacy` 与原生选项回应；交易需 `get_pending_trades`、议价或明确接受／拒绝。`DiplomacyViewCleanup` 会先拒绝活动／排队会话和待处理交易，`DiplomacyDealView` 不由通用关闭直接处理。

当前这些交互在 CLI 中仍主要通过 `tools`／`call` 访问，没有完整命名分类命令；同时存在 InGamePopup／GenericPopup 等通用清理分支，范围还需进一步审查。不能用本轮信息弹窗验证替代全部外交关闭验证，也不能把 `dismiss_popup` 视为统一跳过交互的入口。

## 自动回合耗时

`civ6 debug` 现在自动更新 `turn-timing.json`、`command-timing.json`。普通直接 CLI 标记 actor 为 cli；前台转接器还按调用模型保留 actor。统计只消费既有命令与结果，失败不会改变原命令回应、清除 pending 或重发动作。无需后台轮询。

本轮原始记录已用 `civ6 logs turns --relay <本轮 evidence/relay-v2>` 离线补齐，输出在 [逐回合 JSON](evidence/timing-json/turn-timing.json)、[逐命令 JSON](evidence/timing-json/command-timing.json)。15 个已确认结束回合，T16 保持 partial，未伪造结束。普通 CLI 本体和转接器的自动导出都在 T16 通过实机只读验证，未产生额外推进。

下面的总耗时是确认边界之间的跨度；首个回合从首条有效模型命令开始。CLI 耗时包含预演、发现和 RPC 等待。间隔包含模型／服务、Shell 和人工接力等待，不能称为纯思考时间。T11 同时含 Codex 收尾及 Claude 接手，T16 的局部耗时只到最后一条模型命令，不计测试停止后的闲置。

逐回合与逐命令明细只使用 JSON，不生成 CSV。

观察跨度合计 780.66 秒，其中 CLI 执行 100.21 秒，命令间隔 680.45 秒。日志中显式工具 RPC 累计约 99.22 秒；这些时间来自命令日志，不能单独识别模型内部推理与服务排队。完整模型进程启动／结束跨度另见上表，不与回合跨度混加。

旧回填记录使用墙钟，新自动记录使用单调时钟并保留来源。回合仅由已有 end_turn 的确认回执关闭，普通概览升回合不能补造完成；加载／身份变化切分记录，未知返回不结束回合。用户暂停当前会计入间隔，没有自动识别或扣除暂停；热座专用交接尚未纳入这一计时验收。自动计时使用说明见 [CLI 手册](../../../../docs/cli.md)。
