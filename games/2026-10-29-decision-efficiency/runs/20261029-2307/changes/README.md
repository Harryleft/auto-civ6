## 验收方法

在同一活动回合连续读取旧的五项命令，再读取新入口的结构化视图和默认简报。将结构化数据交给原有领域展示函数，逐项比较旧报告；同时从 CLI 原始事件时间戳统计 RPC 耗时、命令数和 stdout 结果字节。比较期间不执行游戏动作。

模型另外通过命名 CLI 实际建城、研究、生产、移动、驻防、处理完成后的新选择并保存检查点；每次回合推进由原 `TurnProgress` 确认。数据整理脚本只读取证据，不连接或操作游戏。
