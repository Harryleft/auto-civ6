## 决策质量与覆盖边界

本局长期使用临时简化控制器，固定优先表和兜底规则造成开拓者积压、军备与建设失衡，以及 T165 主动退回古典共和并进入三回合无政府状态。它们属于客户端决策错误，不是 CLI 强制选择。用户指出后，原控制器在 T225 停止；[决策质量复核](reports/decision-quality-review.md)保留原因、规则与原请求证据。

同一 T225 随后只做了局面重评及有限调整：改研土木工程、夺回非斯宗主权、四档未成交试价、激活李维·史特劳斯并回读到 2 份 JEANS。用户明确结束本局后，没有继续推进。

本段证明修复后的 CLI 能在该局面持续推进并完成所列操作，不能证明《文明 6》全部操作已覆盖；空军、核战、间谍任务、本方太空项目等未在本段实测，原生终局处理也未验证。策略差不作为判定 CLI 执行失败的依据，命令可执行也不作为策略合理的证明。
