## 是否支持所有操作

**不支持。** 91 个内部工具有命名映射，不等于游戏原生操作全集。当前契约缺少逐格指派／锁定市民、城市间换地、城市／巨作交易、生产队列编辑、加成资源收获、空军再部署／拦截与核打击的正式入口，详见[契约缺口及来源](reports/contract-gaps.md)。任意 Lua 不是普通操作的替代入口，本轮没有使用。

现有能力能完成本轮前中期对局，但调用方必须处理原生待办、完整政策方案和确认门禁，并保留可恢复检查点；本轮证据不足以支持“覆盖全游戏且能无人恢复运行”的结论。
