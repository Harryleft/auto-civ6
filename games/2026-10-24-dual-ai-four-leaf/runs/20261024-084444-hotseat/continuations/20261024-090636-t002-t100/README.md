## 计时口径与边界

`evidence/timing-summary.json` 保存总墙钟耗时、准备耗时、双方 CLI 占用时间、另存时间、故障处理时间，以及逐回合时间。总耗时包括故障修复和回档重跑；各项可能重叠，不直接相加。CLI 时间包括模型思考、工具等待和进程启动。只有原生 `HS_HANDOFF` 回执确认交接，CLI 正常退出不算回合完成。议会可能在同一世界回合增加交接次数。

原地图瑞典继承神级电脑开局奖励，双方初始单位和建城奖励不同；结果用于控制链路与长期运行验证，不能直接解释为模型公平排名。Claude Code 是实际启动入口，本机后端配置不能仅凭 CLI 名称证明为 Anthropic 原生模型。

`evidence/` 保留两个实际 CLI 的原始输出、每笔工具参数与结果、原生 Core 身份回读、存档副本、保存回执、未决请求及显式恢复记录，默认不提交 Git。没有修改父轮次的已完成结果。
