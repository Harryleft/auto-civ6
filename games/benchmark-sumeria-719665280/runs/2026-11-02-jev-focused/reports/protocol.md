# Jev 聚焦任务比较实验预登记

本轮检验：明确当前城市目标、缩小问题范围、采用简短复核和按需调用，是否比上一轮宽泛的全局比较更有用。沿用已有隔离建造者实验授权，使用已确认 T73 起点历史分支；不恢复主对局推进。Jev 仅建议，主模型是唯一 CLI 操作者。保存 T106 当前现场，完成后恢复；本轮不调用 turn end。

在查看本轮 Jev 回复前确定以下边界：

- 主模型依据新鲜事实给出目标、区域分工、候选与代价，不先给候选排序或写参考答案。正常决策只做一次资格／冲突／重要代价复核，不重新完整评价所有候选。
- 可接受的建议必须在当前区域职责内、有可说明的目标收益依据、没有和其他单位争用同一任务，也没有把远处建设当作已批准动作。远处动作未知不自动阻止已核实路径上的检查移动。
- 覆盖限于具体事实错误、遗漏会改变选择的关键事实、任务冲突、越过已批准动作边界、或承担未批准的重要代价。不能以“与主模型口味不同”作为覆盖理由。最后一次次数、不可逆特征移除等重要代价仍由主模型决定；不编造置信度阈值。
- 任务有真实竞争选择且剩余次数允许普通局部调整时，调用 Jev。明显可以简短确认的动作和最后次数的重要取舍由主模型处理，不为凑覆盖率调用。
- 原生动作资格到达后读取；只有存在需要语义比较的竞争选择才第二次调用。补查候选明确描述可能改变哪一决定的信息，不使用泛化的“任何不确定都补查”。
- 另请独立模型只读同一份候选材料，记录主模型单独比较的时间和结论，不能操作游戏、调用 API 或看到 Jev 回复。这个小样本只提供有限参考，不把同意独立模型当正确率；其计时不代表本对话主模型的严格反事实耗时。

记录完整局部窗口：从第一条本轮局面查询到本轮动作及回读结束，包含候选整理、Jev、主模型复核、补查、独立比较协调和记录开销，不扣慢间隔；API 单列。准备保存／加载、最终保存／恢复、离线审计单列。旧实验目标和输入不同，不据此计算加速倍率。独立模型判读时间另列，不能和完整流水线混算。
