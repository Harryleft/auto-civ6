# Jev 单位决策配对 A/B 结果

**在本次两个预登记局面和当前文件式协作流程中，加入 Jev 均增加了完整决策耗时，没有观察到提速。** Jev API 本身只占B臂派发至完成时间的约0.48%／2.89%，不是这两个样本的主要耗时来源。结果不证明 Jev 在所有架构或角色上都无效，也不支持把它推广为所有单位的默认加速层。

| 当前角色与范围 | A：主模型直接决策，Q+D | B：主模型准备→Jev→复核，Q+D | B相对A |
| --- | ---: | ---: | ---: |
| T73建造者，一次目的地检查移动 | 234.098秒 | 314.598秒 | **慢34.4%** |
| T70商人，一条当前可用商路 | 141.627秒 | 184.542秒 | **慢30.3%** |

Q包括共享原始事实查询与整理，D包括臂内候选生成、查询、请求编码、Jev、主模型复核、诊断文件、代理启动和最终消息交接。游戏执行回读、加载和整个实验另列，不能把上表叫整局速度。两例各一对观测，没有重复估计、置信区间或显著性检验；只报告此次差值。

## 如何配对

[预登记协议](protocol.md) 在臂运行前固定了案例、顺序、覆盖条件与计时。每臂使用新建 default agent、fork none、继承相同宿主模型与推理配置，不指定不同模型。隔离对话并禁止读取另一臂／旧实验；共同规则和冻结共享文件相同。没有另行核验底层服务实际模型版本，不能宣称读到某个服务端版本。

建造者先A后B，商人先B后A，均串行运行，根代理在臂工作期间等待、不操作游戏，避免并行争用。额外查询由臂内主模型通过根代理拥有的**同一个**持续CLI relay发出命名只读命令，不新建控制客户端。Jev只返回建议，没有游戏访问或执行权。

共享材料只含原始回执、目标、单位和范围，不给候选或排序；A自行形成候选直接决策，B自行形成候选、仅请求一次Choice、复核后输出。建造者共同准备时曾查三条路径但没有提供给任一臂，耗时保留在Q；两臂独立查询所需路径。商人共享材料完整保留原生8个合法目的地，没有模型筛选。各臂同一简短decision schema，诊断metadata独立保存；metadata实际长度及工具步骤没有强制等量，均计时，不把差值归因成纯模型推理。

建造者共享文件SHA `7b2ee56d05b33b30459080d159cce10d9d9dcb9b6936179de4d573a5dee62a6c`；商人共享文件SHA `4c2def026afdc09b43b2fd40aa5fe9e7bdc38b79cb3c8065eebfb596b9ac02cb`。四份封存decision均绑定正确输入指纹。

## 全部计时

宿主在dispatch前及收到最终READY后记录D；agent自己的work_start／work_end只用于诊断，包含文件、工具及推理，不当作纯思考。Q只实际发生一次，给两臂分别加Q是成本归属，不能把两份Q相加称实际实验时长。[metrics.json](../evidence/metrics.json) 与 [timing.jsonl](../evidence/timing.jsonl) 保留原值。

两次请求均为 `jev-latest`，实际返回 **jev-1.14.0**。建造者输入2041／输出68 tokens，商人输入2052／输出113 tokens。B均接受建议，无API失败／重试，没有强制凑一致。

建造者A追加1条原生路径，B追加3条。A、B的metadata都记录首次使用系统python读取relay帮助时导入失败，随后改用项目uv帮助；均未进入游戏请求，也不是未知动作重发。两臂全部时间保留，错误耗时均未独立精确切分，不能删掉后报最好样本，也不能将建造者差值当成纯Jev因果效应。没有该已知错误的商人样本同样更慢。

即使仅作“其他步骤完全不变、API变成零耗时”的算术敏感性，B的D仍分别为A的约1.84倍／1.46倍。这不是实际去掉API的反事实试验；它只说明单独加速Jev网络往返不足以抵消本次流程的成本。主要时间在API之外，但现有记录不能精确区分推理、工具交接、查询规划、排队、请求构造及记录各占多少。

## 对迁移与瓶颈的判断

**可以迁移的是“领域事实＋候选＋有限建议＋主模型复核”的通信方法；不能直接迁移的是已验证的加速收益。** 商人比建造者更接近固定原生候选，本例仍没有提速。建造者专用的改良资格校验也不能直接替代商路、定居、战斗或伟人动作的资格与确认。

当前收益障碍是新增管线没有省掉足够的主模型工作：B仍需要理解事实、生成候选、编码请求和复核，再增加一次调用。冷启动agent、工具和文件交接是本实验实现的一部分；改为同一持久主模型上下文、直接SDK、复用非策略事实格式或多个独立问题同请求，可能改变结果，本轮没有测试这些架构。内部工作窗口也显示B更慢，但它仍包含工具和记录，不能称为纯决策算法差异。

建议保持Jev为可选实验，暂不扩展成所有单位默认决策层。优先验证减少事实整理和重复主模型判断的流程，复用已知事实格式时仍保留新鲜度／未知门禁；策略候选和重要取舍继续由模型决定，不编写通用策略脚本。已有商路、驻防等持续状态也不能仅因每回合出现就假定需要一次新的Jev判断。

整局速度还取决于可替代决策占总耗时的比例f及其稳定局部加速s；即便局部s>1，总体也受 `1 / ((1-f)+f/s)` 限制。这只是固定其他因素的成本分解，f和稳定s本轮均未测量。两个角色单例不能支持所有单位或整局两倍。
