# auto-civ6 架构可视化（2026-10-25 · CLI 唯一入口版）

针对「CLI 作为唯一 AI 操作面」调整后的当前工作树（基线提交 `042ea57` 加本轮入口收敛补丁）生成的单文件架构页面：
12 个章节、8 张手写 SVG 图，覆盖系统全景、运行时分层、模块依赖、动作生命周期、回合推进、端到端时序、
会话替换与检查点、外交交易与议会状态机、CLI 命令面、验证体系、目录地图与设计规则。

页面主线：**AI 只发现并执行 `civ6` 命名命令；MCP 降为 CLI 内部的 stdio 通信实现，客户端不注册、不直连。**

## 打开方式

- 直接双击 `index.html`（或浏览器打开）即可：样式、脚本、图形全部内联，**不引用任何外部字体、CDN 或网络资源**。
- 左侧导航按章节跳转；鼠标悬停在图上任意卡片上，会高亮该卡片并淡化其他卡片。

## 重新生成

```bash
cd materials/architecture-visualization/2026-10-25
python3 build.py
```

只依赖 Python 标准库（`build.py` 会用 `git rev-parse` 取当前短提交号；不在 git 仓库内时显示 `unknown`）。
图与文案都在 `diagrams_*.py` / `build.py`，没有构建缓存，也没有外部依赖。

## 内容来源与范围

- 结构、状态机与数字来自当前工作树：`src/civ_mcp/`、`docs/`（含 `docs/architecture.md`、`docs/cli.md`、
  `docs/specs/`、`docs/acceptance/`）、`tests/`、`fixtures/`、`games/`。
- 关键数字：90 个基础工具（全部有命名入口）、33 组 / 142 个命名命令（含 3 个热座实验命令）、
  普通会话可见 89 个工具（`run_lua` 仅 `--developer`）、132 个测试文件 / 2,146 个测试函数。
- 图中的行号与文件规模是生成时对工作树的实测（`wc -l`、`grep -c`、import 关系扫描），重构后会偏移。
- **本页只用于解释结构，不构成行为契约**：以 `docs/` 中的指南、规格和验收记录为准；旧验收通过记录只对当时的受测版本有效。
- 生成过程未连接游戏、未启动 FireTuner、未运行实机测试；“实机未运行”指本页自身，不代表项目当前状态。
