# 云文档
## Docs
- [云文档概述](https://open.feishu.cn/document/server-docs/docs/docs-overview.md): 飞书云文档提供在线文档、电子表格、多维表格、知识库和云空间等产品的开放能力，支持文件上传下载、文档创建编辑及管理。通过API调用实现高效的文档管理和协作，适用于多种业务场景。
- [云文档常见问题](https://open.feishu.cn/document/server-docs/docs/faq.md): 本文档解答飞书云文档常见问题，包括应用权限与文档权限的区别、如何申请和开通权限、访问云文档资源的步骤及相关token获取方法。适用于开发者在集成飞书云文档API时遇到的权限管理和资源访问问题。
- [云空间概述](https://open.feishu.cn/document/server-docs/docs/drive-v1/introduction.md): 飞书开放平台云空间提供管理云文档资源的接口，支持文件、文件夹、素材等多种资源操作。本文档介绍了云空间资源定义、使用限制及能力接入流程，帮助用户高效管理云文档。
- [云空间常见问题](https://open.feishu.cn/document/server-docs/docs/drive-v1/faq.md): 飞书云空间常见问题解答，涵盖获取文件夹、文件及素材的token信息，应用身份权限开通，文件下载权限设置等。提供详细步骤和接口调用指南，帮助用户更好地管理和使用飞书云文档。
- [文件夹概述](https://open.feishu.cn/document/docs/drive-v1/folder/folder-overview.md): 本文档介绍了飞书云空间中文件夹的基础概念、文件夹 token 的获取方式以及相关 API 列表。文件夹是用于管理文件和其他文件夹的容器，每个文件夹都有唯一的 token。你可以通过浏览器或调用开放平台接口获取文件夹的 token。
- [获取我的空间（根文件夹）元数据](https://open.feishu.cn/document/server-docs/docs/drive-v1/folder/get-root-folder-meta.md): 获取我的空间（root folder）元数据接口用于获取用户云空间的元数据，包括文件夹的token、ID及所有者ID。支持自建和商店应用，需具备相应权限。通过访问凭证进行身份鉴权，确保数据安全。
- [获取文件夹中的文件清单](https://open.feishu.cn/document/server-docs/docs/drive-v1/folder/list.md): 该接口用于获取用户云空间指定文件夹中的文件清单，包括名称、类型、创建时间等信息。支持自建应用和商店应用调用，权限要求灵活。接口仅获取当前层级文件信息，不支持递归获取子文件夹内容。
- [获取文件夹元数据](https://open.feishu.cn/document/server-docs/docs/drive-v1/folder/get-folder-meta.md): 飞书开放平台提供获取文件夹元数据的API接口，通过文件夹token获取文件夹的ID、名称、创建者ID等信息，支持自建应用和商店应用调用。
- [新建文件夹](https://open.feishu.cn/document/server-docs/docs/drive-v1/folder/create_folder.md): 通过飞书开放平台的API在云空间中创建文件夹，支持自建和商店应用。接口调用限制为5次/秒，单层节点上限1500个。提供详细的请求和响应格式及错误码说明，确保开发者顺利集成和使用。
- [移动或删除文件夹](https://open.feishu.cn/document/server-docs/docs/drive-v1/folder/move-delete-folder.md): 飞书开放平台提供移动或删除文件夹的API接口，帮助用户高效管理云空间中的文件夹。操作类似于文件的移动与删除，用户可参考相关接口文档进行操作。
- [查询异步任务状态](https://open.feishu.cn/document/server-docs/docs/drive-v1/file/async-task/task_check.md): 飞书开放平台提供查询异步任务状态的API，支持查询删除和移动文件夹的异步任务状态。通过GET请求获取任务执行状态，需提供task_id和access_token。
- [文件概述](https://open.feishu.cn/document/docs/drive-v1/file/file-overview.md): 本文档介绍了飞书云空间内文件的基础概念、文件 token 的获取方式以及文件相关的 API 列表。文件包括在线文档、电子表格、多维表格等，支持通过浏览器和开放平台接口获取文件 token。
- [获取文件元数据](https://open.feishu.cn/document/server-docs/docs/drive-v1/file/batch_query.md): 获取文件元数据接口用于通过文件token获取文件的详细信息，如标题、所有者、创建时间等。支持自建和商店应用，需相应权限。请求频率限制为1000次/分钟。接口返回文件元数据列表及失败的文档token信息。
- [获取文件统计信息](https://open.feishu.cn/document/server-docs/docs/drive-v1/file/get.md): 获取文件统计信息接口用于获取各类文件的流量统计信息和互动信息，包括阅读人数、阅读次数和点赞数。支持自建应用和商店应用，需具备相应权限。
- [获取文件访问记录](https://open.feishu.cn/document/server-docs/docs/drive-v1/file-view_record/list.md): 获取飞书云文档、电子表格、多维表格等文件的历史访问记录，包含访问者信息及最近访问时间。支持自建和商店应用，需获取用户基本信息或文档访问记录权限。
- [创建云文档](https://open.feishu.cn/document/docs/drive-v1/file/create-cloud-document.md): 飞书开放平台提供创建云文档的接口，包括创建文档、电子表格和多维表格。用户可以通过模板快速创建目标文档类型，提升工作效率。详细接口文档和操作指南帮助用户轻松完成文档创建。
- [复制文件](https://open.feishu.cn/document/server-docs/docs/drive-v1/file/copy.md): 飞书开放平台提供复制文件API，支持将用户云空间中的文件复制到其他文件夹。该异步接口不支持复制文件夹，具有节点和调用频率限制。适用于自建和商店应用，需具备相应权限。
- [移动文件或文件夹](https://open.feishu.cn/document/server-docs/docs/drive-v1/file/move.md): 飞书开放平台提供移动文件或文件夹的API，支持将文件或文件夹移动到用户云空间的其他位置。接口不支持并发调用，频率限制为5 QPS及10000次/天。支持自建应用和商店应用，需具备相应权限。
- [删除文件或文件夹](https://open.feishu.cn/document/server-docs/docs/drive-v1/file/delete.md): 飞书开放平台提供删除云空间内文件或文件夹的API，支持异步执行文件夹删除任务。确保应用或用户具备相应权限，接口调用频率限制为5 QPS。
- [创建文件快捷方式](https://open.feishu.cn/document/server-docs/docs/drive-v1/file/create_shortcut.md): 通过飞书开放平台的API创建文件快捷方式，便于在云空间中管理文件。支持自建和商店应用，需权限验证。接口调用频率限5次/秒，10000次/天。
- [搜索云文档](https://open.feishu.cn/document/server-docs/docs/drive-v1/search/document-search.md): 飞书开放平台提供搜索云文档接口，通过关键词搜索当前用户可见的云文档。支持自建应用和商店应用，需具备相应权限。可根据搜索关键词、文件数量、偏移量等参数进行定制化搜索，返回包含文件信息的列表。
- [上传文件概述](https://open.feishu.cn/document/server-docs/docs/drive-v1/upload/multipart-upload-file-/introduction.md): 飞书开放平台提供多种文件上传接口，支持将本地文件上传至云空间。根据文件大小和网络状况选择直接上传或分片上传，确保上传成功率。注意容量限制和调用频率限制，以避免错误码。
- [上传文件](https://open.feishu.cn/document/server-docs/docs/drive-v1/upload/upload_all.md): 通过飞书开放平台上传文件接口，将指定文件上传至云空间指定目录中。支持自建应用和商店应用，文件大小不得超过20MB，调用频率上限为5 QPS。需提供文件名称、上传点类型、云空间文件夹token、文件大小等参数。
- [分片上传文件](https://open.feishu.cn/document/server-docs/docs/drive-v1/upload/multipart-upload-file-/upload_prepare.md): 飞书开放平台提供分片上传文件的预上传接口，帮助用户获取上传事务ID和分片策略。接口支持自建和商店应用，需满足调用频率限制。上传事务有效期为24小时，文件分片固定为4MB。
- [分片上传文件](https://open.feishu.cn/document/server-docs/docs/drive-v1/upload/multipart-upload-file-/upload_part.md): 飞书开放平台提供分片上传文件的能力，通过上传事务 ID 和分片策略上传文件分片，支持自建应用和商店应用。接口频率限制为 5 QPS，10000 次/天。完成上传后需调用完成上传接口。
- [分片上传文件](https://open.feishu.cn/document/server-docs/docs/drive-v1/upload/multipart-upload-file-/upload_finish.md): 飞书开放平台提供分片上传文件完成上传接口，确保文件上传成功。该接口不支持并发调用，频率限制为5 QPS，10000次/天。调用该API需具备相应权限，并使用tenant_access_token或user_access_token进行授权。
- [下载文件](https://open.feishu.cn/document/server-docs/docs/drive-v1/download/download.md): 飞书开放平台提供下载云空间文件的API，支持分片下载。确保应用拥有文件下载权限，接口调用频率上限为5 QPS。支持自建和商店应用，需使用正确的文件token和授权信息。
- [导入文件概述](https://open.feishu.cn/document/server-docs/docs/drive-v1/import_task/import-user-guide.md): 飞书开放平台支持将本地文件如Word、TXT、Markdown、Excel等格式导入为云文档，并放置到云空间指定目录中。本文介绍了导入文件的完整步骤，包括上传文件、创建导入任务和查询导入结果。
- [创建导入任务](https://open.feishu.cn/document/server-docs/docs/drive-v1/import_task/create.md): 该接口用于创建导入文件任务，将本地文件导入为飞书在线云文档。支持异步操作，需要调用查询接口获取结果。前提需获取源文件的token。
- [查询导入任务结果](https://open.feishu.cn/document/server-docs/docs/drive-v1/import_task/get.md): 飞书开放平台提供查询导入任务结果的API，通过导入任务ID轮询获取导入状态和结果。支持自建和商店应用，需具备相应权限。API响应包括任务状态、错误信息、文档URL等，帮助开发者高效管理云文档导入流程。
- [导出云文档概述](https://open.feishu.cn/document/server-docs/docs/drive-v1/export_task/export-user-guide.md): 飞书开放平台提供导出云文档功能，支持将飞书文档、电子表格、多维表格导出为本地文件，包括 Word、Excel、PDF、CSV 格式。导出文件需在任务结束 10 分钟内下载，支持启用水印。
- [创建导出任务](https://open.feishu.cn/document/server-docs/docs/drive-v1/export_task/create.md): 创建导出任务接口用于将飞书文档、电子表格、多维表格导出为本地文件，支持Word、Excel、PDF、CSV格式。该接口为异步操作，需通过查询接口获取结果。
- [查询导出任务结果](https://open.feishu.cn/document/server-docs/docs/drive-v1/export_task/get.md): 飞书开放平台的导出任务结果查询接口，通过导出任务ID获取导出文件的token，支持导出PDF、XLSX等格式。确保调用者与创建者一致，权限要求包括导出云文档权限。
- [下载导出文件](https://open.feishu.cn/document/server-docs/docs/drive-v1/export_task/download.md): 飞书开放平台提供下载导出文件的API，通过导出任务结果的token，快速获取云文档导出文件。注意导出文件需在任务结束10分钟内下载。支持自建应用，需具备相应权限。
- [素材概述](https://open.feishu.cn/document/server-docs/docs/drive-v1/media/introduction.md): 飞书开放平台提供素材管理能力，支持在云文档中上传、下载和获取素材。素材包括图片、视频等，具有唯一token标识。通过多种接口实现素材上传与下载，支持分片上传以提高稳定性。
- [上传素材](https://open.feishu.cn/document/server-docs/docs/drive-v1/media/upload_all.md): 飞书开放平台的上传素材接口支持将文件、图片、视频等素材上传至指定云文档中，文件大小限制为20MB。该接口适用于自建和商店应用，需具备相关权限。通过此接口，用户可在云文档中高效管理素材，提升协作效率。
- [分片上传素材](https://open.feishu.cn/document/server-docs/docs/drive-v1/media/multipart-upload-media/upload_prepare.md): 飞书开放平台提供分片上传素材的预上传功能，通过发送初始化请求获取上传事务 ID 和分片策略，为上传素材分片做准备。接口调用频率限制为5 QPS，10000次/天，上传事务 ID 和进度在24小时内有效。
- [分片上传素材](https://open.feishu.cn/document/server-docs/docs/drive-v1/media/multipart-upload-media/upload_part.md): 飞书开放平台提供分片上传素材功能，通过上传事务 ID 和分片策略上传素材分片，支持自建应用和商店应用。接口调用频率为5 QPS，权限包括查看、评论、编辑和管理多维表格、文档等。
- [分片上传素材](https://open.feishu.cn/document/server-docs/docs/drive-v1/media/multipart-upload-media/upload_finish.md): 该接口用于完成飞书云文档分片上传素材的过程，需在分片全部上传后调用。支持自建和商店应用，权限要求包括查看和管理多维表格、文档、云空间等。调用频率限制为5 QPS，每天最多10000次。
- [下载素材](https://open.feishu.cn/document/server-docs/docs/drive-v1/media/download.md): 飞书开放平台提供下载云文档素材的API，支持通过请求头添加Range参数分片下载，需具备素材下载权限。接口调用频率限制为5 QPS，10000次/天。适用于自建应用和商店应用，支持多种权限配置。
- [获取素材临时下载链接](https://open.feishu.cn/document/server-docs/docs/drive-v1/media/batch_get_tmp_download_url.md): 获取云文档中素材的临时下载链接，链接有效期24小时。确保应用拥有素材下载权限，否则返回403状态码。支持自建和商店应用，需提供素材文件的token。接口频控特殊，支持多维表格、电子表格和文档的下载权限。
- [文档版本概述](https://open.feishu.cn/document/server-docs/docs/drive-v1/file-version/overview.md): 飞书开放平台支持在线文档和电子表格的版本管理，提供创建、删除和查看版本的API。版本依附于文件，支持通过参数如版本号、创建时间等进行管理。适用于商店应用和自建应用，助力企业高效管理文档版本。
- [创建文档版本](https://open.feishu.cn/document/server-docs/docs/drive-v1/file-version/create.md): 飞书开放平台提供创建文档版本的API，支持在线文档和电子表格。该接口为异步接口，需具备相应权限。支持自建应用和商店应用，通过POST请求创建文档版本，返回文档版本信息。
- [获取文档版本列表](https://open.feishu.cn/document/server-docs/docs/drive-v1/file-version/list.md): 获取飞书云文档或电子表格的版本列表，支持分页查询和多种文档类型。通过API调用可查看、创建、删除文档版本，需具备相应权限。适用于自建应用和商店应用，帮助用户管理文档版本历史。
- [获取文档版本信息](https://open.feishu.cn/document/server-docs/docs/drive-v1/file-version/get.md): 获取飞书云文档或电子表格指定版本信息的API，支持查看标题、标识、创建者等信息，适用于自建和商店应用。通过指定file_token和version_id获取文档版本详情，需具备相应权限。
- [删除文档版本](https://open.feishu.cn/document/server-docs/docs/drive-v1/file-version/delete.md): 飞书开放平台提供删除文档版本的API，支持自建和商店应用。通过该接口，开发者可以删除基于在线文档或电子表格创建的版本。接口支持高频调用，需具备相应权限。
- [订阅云文档事件](https://open.feishu.cn/document/server-docs/docs/drive-v1/event/subscribe.md): 飞书开放平台提供的云文档事件订阅接口，支持订阅文件编辑、多维表格变更等事件。仅文档拥有者和管理者可订阅，需确保应用或用户具备相关权限。支持自建应用和商店应用，提供详细的请求和响应参数说明，帮助开发者高效管理文档事件通知。
- [查询云文档事件订阅状态](https://open.feishu.cn/document/docs/drive-v1/event/get_subscribe.md): 查询云文档事件订阅状态接口帮助用户确认文档事件的订阅情况。确保应用或用户为文档所有者或管理者，正确配置订阅方式。支持自建和商店应用，需具备相应权限。接口响应包括订阅状态及错误码信息。
- [取消云文档事件订阅](https://open.feishu.cn/document/server-docs/docs/drive-v1/event/delete_subscribe.md): 取消云文档事件订阅接口用于停止接收文档通知，需确保应用或用户为文档所有者或管理者。支持自建和商店应用，需具备相应权限。调用频率限制为每分钟10次。
- [多维表格字段变更](https://open.feishu.cn/document/server-docs/docs/drive-v1/event/list/bitable_field_changed.md): 飞书开放平台多维表格字段变更事件，触发文件编辑事件。支持自建和商店应用，需权限订阅。事件体包含详细字段变更信息，便于管理和操作。
- [多维表格记录变更](https://open.feishu.cn/document/docs/bitable-v1/events/bitable_record_changed.md): 飞书开放平台的多维表格记录变更事件，当订阅的多维表格记录发生变更时触发。支持自建应用和商店应用，提供Webhook推送方式。需具备相关权限才能订阅和获取敏感字段信息。
- [文件标题变更](https://open.feishu.cn/document/server-docs/docs/drive-v1/event/list/file-title-update.md): 云文档标题变更事件，当被订阅的云文档标题发生变更时触发。支持自建应用和商店应用，需相应权限。事件类型为drive.file.title_updated_v1，通过Webhook推送。
- [文件已读](https://open.feishu.cn/document/server-docs/docs/drive-v1/event/list/file-read.md): 飞书开放平台提供文件已读事件，当云文档被打开时触发。支持自建和商店应用，需权限订阅。事件体包含事件类型、用户信息、文档类型等详细信息，便于开发者管理和监控文档访问情况。
